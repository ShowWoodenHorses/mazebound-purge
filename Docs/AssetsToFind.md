## 0. Общие требования

- **Стиль** — Synty POLYGON (низкополигональный, плоские цвета, атлас-текстура). Эффекты — мультяшные, **без крови и следов от пуль** (как в Maze).
- **Лицензия** — коммерческая, для веба и мобильных (Unity Asset Store — ок; звуки — CC0 или с разрешением коммерции, указание автора записать сюда).
- **Персонажи (люди и гуманоиды)** — Humanoid-скелет, совместимый с Synty (тогда работают клипы Mixamo и запекание анимации для рядовых). Пивот у ног, лицо по +Z.
- **Животных и четвероногих нет** (решение пользователя 2026-10-16): анимаций, особенно атак, для них не найти.
- **Размер**: веб-загрузка до первого боя ≤ 20 МБ — текстуры паков всё равно урежем до 1024/512, но лучше брать паки с общим атласом, а не с текстурой на каждую модель.
- **Звуки** — WAV/OGG, 44.1 кГц, моно для игровых (стерео — только UI и музыка), короткие и обрезанные без тишины в начале. Несколько вариантов одного звука (`attack1/2/3`) — хорошо: билдер подхватывает их по префиксу.
- Чего **не искать** — рисую сам кодом/шейдерами: иконки UI и карточек, рамки редкости, колпак безопасной зоны, предупреждения способностей (зоны/линии на полу), свечение чемпионов, огонь/лёд/кислота на клетках (маски), трассеры, цифры урона, туман, дуги урона, стрелки к боссу.
