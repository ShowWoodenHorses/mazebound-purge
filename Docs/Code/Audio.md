# Звук

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Звук
- Исходники — `Assets/_Project/Sounds/<Player|Weapon|Other|Zombie|UI>` и `Music/` (menu, game).
  - **Purge → Dev → Build Audio** (`AudioBuilder`): импорт (звуки — Vorbis, моно кроме UI, короткие Decompress On Load, **WebGL — MP3** (короткие клипы Unity декодирует `decodeAudioData`, мобильный Chrome не декодирует AAC — звуки молчали; у WebGL-override частота только явная, Preserve молча отклоняется; **короткие петли** (`loop`, `*_loop`, `*_flight`, ≤ 6 с) на WebGL — **PCM**: MP3 не бесшовный, кодек добавлял ~40 мс тишины в начало клипа — у огнемёта на каждом круге петли была пауза (этап Э3); длинная петля `light_loop` осталась MP3); музыка — Streaming, группа **Purge Music** — бандл на трек), `AudioCatalog` (`Data/Audio`, Addressable `"Audio/Catalog"`, группа Purge Shared) по **именам файлов** (шаблоны в билдере; новые варианты с тем же префиксом подхватываются), настройка (громкость ≤ 1, разброс тона, `Range`, `MaxVoices`, `MinInterval`) при пересборке сохраняется.
  - Музыка — `AssetReferenceT<AudioClip>`, грузится только пока играет (свой owner), `LoopOverlap` — следующий круг поверх затухающего хвоста.
- `AudioService` (Application, проектный скоуп; тикает `AudioTickDriver` с unscaled time): пул 24 голосов, всё 2D — громкость/пан от расстояния до игрока считают вьюхи (`SoundMath`: `Attenuation`, `Pan`; стены звук не глушат, как и в геймплее).
  - Каналы `Interface`/`Level`: уровень на паузе — `SetLevelPaused`, конец уровня — `StopLevelSounds` (только петли при Completed/Failed, чтобы смерть доиграла). Громкость из `SettingsService` (`PreviewVolumes` при перетаскивании, `SavePreviewed` при закрытии настроек).
- `AppAudioPresenter` (проектный): музыка по `GameFlowState` (тише на паузе/карте/результате), звуки пауза/карта, джингл результата и строки итога по одной (звук `Star` с растущим тоном); окно смерти — тише музыка без звука паузы, выход из него — звук «продолжить». Кнопки — компонент `UiSound` (Click / Back / None — когда открывающийся экран звучит сам; клик по неактивной → Denied), ставит `RuntimeScenesBuilder`, событие через `UIRoot.RequestSound`.
- `LevelAudioPresenter` (шаг `SpawnZombies` после `ZombieViewPresenter`, `ILevelTickable` — таймеры не идут на паузе): шаги игрока (`SoundEventBus` Step; по поверхности — 7г: `Grass` → `FootstepGrass` (`Player/step_grass*`), `Ground` → `FootstepGround` (`Player/step_ground*`), обычный пол — `VisualTheme.FloorSteps`, нет звука — `Footstep`), эмбиент биома (7г: петля `AudioCatalog.Ambience(id темы)` ← папка `Sounds/Ambient/<id темы>/`, весь уровень, на паузе — с каналом уровня), атаки, перезарядка (короткий звук ждёт, чтобы закончиться с перезарядкой; длинный ускоряется до 1.5×; смена оружия его снимает), пули о стену, двери (`PlayerInteraction.Interacted`), подбор, урон/смерть игрока, зомби: рык при входе в Alert + один стингер на погоню, шаги по пройденному пути, стоны в покое, атака, урон/смерть — по `ZombieViewPresenter.HitShown/DeathShown` (синхронно с клипом).
  - Голос типа зомби — тон из `AudioCatalog.ZombieVoices` (по id). Факелы: петля на ближайших `MaxTorchLoops` источниках света. Ещё: выброс оружия, редкий дроп (`RareDropFrom`), метательное, взрывы эффектов, петля огня, сердцебиение при малом HP, падение тела после смерти, конец волны (`WaveCleared` ← `Player/win`, кроме последней — 6б), повышение уровня (`LevelUp` ← `Player/level_up`) и воскрешение (`Revive` ← `Player/revive`) — 6д; монетка у HUD (`Coin` ← `Other/coin*`, `RunFeedbackPresenter`).
  - Оружие — не здесь, а в `WeaponAudioPresenter`; орда и двери — в `HordeAudioPresenter`.
- `HordeAudioPresenter` (6е2, шаг `SpawnZombies`, после звуков оружия): способности — `AbilityModule.CastSound` в начале каста и `ReleaseSound` при срабатывании (поля модуля — выпадающий список папок `Sounds/Monster/<звук>` → `AudioCatalog.MonsterSound(name)`, `MonsterSoundAttribute`); зов зовущего (`SoundType.Call` ← `Monster/call*`), рикошет о броню (`CombatTargets.ArmoredHit` ← `Monster/armor_hit*`), появление чемпиона (`HordeSystem.ChampionMade` ← `Monster/champion*`), двери: открыть/закрыть — по `DoorSystem.DoorChanged` (любой, и игрок; выбитая — без звука открытия), удар монстра `DoorHit` ← `Other/door_hit*`, выбита `DoorBroken` ← `Other/door_broken*`.
  - Звуки способностей: `arrow` (лук), `spit` (плевок), `icicles` (сосульки), `rage_roar` (ярость Громилы), `shaman_spell` (удар Шамана), `shaman_raise` (подъём); черновые данные — `OfficersBuilder` (Seed, `EnsureRage`).
- UI-звуки по коду — `UIRoot.RequestSound(UiSoundKind)`: `Window` (окно подтверждения ← `UI/window_exit_level`), `CardsShown`/`CardChosen`/`CardReroll` (`CardsPresenter` ← `UI/cards_show*`, `card_pick*`, `card_reroll*`); кнопки карточек сами не щёлкают (`UiSound.None`).
- `WeaponAudioPresenter` (этап 4в, шаг `SpawnZombies`, тик): выстрел группы с тоном/громкостью оружия (`WeaponDefinition.SoundPitch/SoundVolume`), непрерывный огонь петлёй (`start` → `loop` пока атака идёт → `end`), хвост раз после одиночного или в конце очереди, `Cycle` (помпа/затвор) и гильзы с задержкой, «мало патронов» (≤ `LowAmmoShare` магазина), щелчок пустого (`DryFired`), «достать» при смене, перезарядка шагами (`ReloadStep.At` — доля времени, 1 = кончается с перезарядкой; без шагов — одна запись, подогнанная по времени), попадания (`CombatTargets.WeaponDamaged`: свой `Hit` оружия, ближнее — в момент удара клипа, иначе `MonsterHit`), убийства орды (`KillPop` + `KillSplat`), взрывы снарядов по радиусу, петля полёта снаряда (`Flight`).
  - Звуки оружия — по `WeaponDefinition.SoundGroup` (поле `Sound` — выпадающий список папок групп, `WeaponSoundGroupAttribute`; пусто = id; строковые ссылки на контент в инспекторе делать списками, не текстом): группа = папка `Sounds/Weapon/<группа>/` (`attack*`, `start/loop/end*`, `reload*`) → `AudioCatalog.WeaponSounds`
  - общие части — `Sounds/Weapon/_Parts/<часть>/` → `AudioCatalog.Parts` (`SoundPart`, ссылки из группы — списки `WeaponSoundPart`); нет звука в группе — общий. Новая группа получает черновые части по виду оружия (`AudioBuilder.DefaultParts`), дальше правится в каталоге.
- Тесты: `AudioService.MusicHandleCount` вычитать при подсчёте утечек handle'ов (музыка грузится асинхронно по ходу flow), `PlayingCount(channel)`.
