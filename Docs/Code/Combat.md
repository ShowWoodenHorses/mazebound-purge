# Бой, метательное, зоны, состояния, дроп

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Бой
- `PlayerCombat` (тик **до** `PlayerSystem`; код один раз на модуль атаки): **стрельба на ходу** — игрок идёт, корпус смотрит на прицел (`PlayerSystem.AimAt`, `IsAiming`): при атаке и **боевая стойка** `StanceTime` (1 с) после неё — прицел остаётся на последней цели, корпус не мечется между выстрелами; **на ПК корпус всегда смотрит на курсор**; `Facing` — корпус, `MoveDirection` — ноги; вид поворачивает корпус в прицеле плавнее (`PlayerViewPresenter.AimTurnSpeed` 450°/с против 900°/с), скорость × `PlayerSystem.WeaponSpeed` (= `MobilityModule` активного оружия). Прицел: мышь (`IAimPointer` → `CameraAimPointer`, точка на полу; `Look` только `<Mouse>/position` — касания не целятся), правый стик, иначе стик движения/`Facing` — с автонаведением (`AssistedDirection`: цель в конусе ±30° в `Attack.AimRange`, без стен; у стика движения — затем ближайшая цель вокруг: убегая, игрок стреляет в толпу) или снапом. Cooldown копит остаток кадра (≤ 0.05 с) — темп не зависит от FPS. Патроны: атака берёт `PerAttack` из магазина; пустой — перезарядка из `AmmoStock` (частичная, если мало); нет ничего — `DryFired` и `IsOutOfAmmo` (красная обводка). Перезарядка вручную — Reload (R, геймпад North) или клавиша активного слота. Цели — `CombatTargets` (орда `HordeSystem` + `IDamageable` зомби Maze): `Segment`, `Collect` (круг/конус), `IsClear` (`BlocksBullets`), весь урон — `Damage` → событие `Damaged` для вида. Ближний — все в секторе при `IsClear` (`LastMeleeHits` — объекты, `LastMeleeTargets` — все), лёд мёрзлых дверей; цепь — `ChainPoints`. Удержание: только `Automatic` повторяет.
- **Ощущение стрельбы (этап 4в):** модуль оружия `FeelModule` (`WeaponDefinition.Feel`, без модуля — `FeelModule.Default`), множители каналов `FeelChannels` (проектный скоуп, сессия; стенд). Геймплей — `WeaponFeelSystem` (шаг `InitializeSystems`) по `CombatTargets.WeaponDamaged` (событие на каждый урон оружия, и взрыв снаряда — с его оружием, толкает от центра): `HordeSystem.Push` (скорость × `KnockScale` массы монстра — тяжёлые летят меньше, неподвижные никак (5г); затухает `PushDamping`, стены останавливают; у трупа — отлёт), `Stagger` (не идёт и не бьёт); по `PlayerCombat.Attacked` — `PlayerSystem.Push` (отдача, `PushVelocity`). Вид — `WeaponFeelView`: `TopDownCamera.Kick/Shake` (смещение поверх слежения, база отдельно), `PlayerWeaponPresenter.Kick` → `CharacterWeaponRig.Kick` (пружина: оружие назад и стволом вверх, корпус назад — до IK левой руки; оружие в ладони каждый кадр возвращается в 0), свет выстрела — глобалы `_PurgeShotLightPosition/Color` (`PurgeShotLight` в `PurgeLighting.cginc`, гаснет за 0.07 с), `HordeRenderer.SetHitLook` (сила вспышки и «вмятины» — сплющивание матрицы на `DentTime`), брызги цвета монстра (`HordeVisualDefinition.SplashColor`) и кольцо под целью — две системы частиц `Emit` (материалы `CombatVisualDefinition.Splash/HitRing`), ближнее — в момент удара клипа; вибрация — `VibrationService` (Application/Platform: веб `PurgePage_Vibrate`, Android `Vibrator`, моторы геймпада; не чаще 60 мс; `Enabled`). Замирания кадра нет (отложено, решение пользователя 2026-10-17).
- `BulletSystem` (тик после взаимодействия): пул `Bullet` (дальность `RangeLeft`, пробитие `Pierce`, `Explosive`), каждый тик `CombatTargets.Segment(prev, next)` → цель / стена-закрытая дверь / ничего; взрыв — в точке попадания, у стены (со стороны стрелка) или в конце дальности (`Explode`, событие `Exploded`); события `Spawned`, `Ended`.
- `ISpatialQueryService` (`SpatialQueryService`, Gameplay/Spatial): объекты регистрируются `Add/Remove` (зомби — на их этапе), позиции читаются вживую; стены — `GridRaycast` (Core) с `LevelOpacity`.
- Звуки §71 (геймплейные, для слуха монстров): `SoundEventBus.Emit(type, position, radius)` — Melee/Ranged (`WeaponDefinition.SoundRadius`: калибр × глушитель), Step (`PlayerFootsteps`), Door, Pickup, Throw, Explosion, Call (зов зовущего, 5б). Орда слышит по проходам (`HordePerception` → `NoiseField`: стены гасят, закрытая дверь × 0,5 — Monsters.md), зомби Maze — по прямой; без накопления. Кольца шума `NoiseWavesView` (5б) — только у выстрелов (Ranged), радиус с глушителем; кольца шагов, дверей, подбора убраны. Воспроизведение — раздел «Звук».
- Вид: `CombatVisualDefinition` (Addressable "Combat/Visual", грузит `SharedDefinitionsService`) → `CombatViewPresenter` (ObjectPool, эффекты только в видимых клетках): трассер из `Muzzle` сходится с линией пули (геймплейная пуля летит из центра игрока), вспышка у дула и гильза ставятся в `LateTick` после позы оружия (регистрация после `PlayerWeaponPresenter`), искры по нормали стены, «звёздочка» на попадании (пуля и ближний), дуга `SwingArc` по `MeleeArc`/`MeleeRange`. Визуал ближнего боя (дуга, «звёздочки», реакция зомби — вспышка, `Hit`, смерть) ждёт момента удара в клипе: `PlayerViewPresenter.LastMeleeContactDelay` = `AttackContact{i}` (дефолты параметров контроллера, замеряет Build Player Animations) × cooldown, направление дуги — `AttackSweep{i}` (`LastMeleeSweep`); урон по геймплею — сразу (решение пользователя). Свои эффекты (стиль мультяшный, без крови и следов пуль) — **Purge → Dev → Build Combat Effects** (`CombatEffectsBuilder`, `Art/Effects`, шейдеры `Purge/Particle`, `Purge/SwingArc`); `CombatEffect` на корне префаба — длительность и перезапуск частиц. Вспышка модели при уроне — `HitFlash` (MaterialPropertyBlock `_HitFlash` в `Purge/Lit`), красная пульсация краёв экрана — `HudScreen.PulseDamage`. `LevelWarmup` проматывает системы частиц на 0.02 с, чтобы их нарисовать. Шейдеры эффектов — с `ColorMask RGB` (не портят альфу кадра).
- **Эффекты из паков (этап Э1):** **Purge → Dev → Build Pack Effects** (`FxPackBuilder`, список `Art/Effects/FxImport.asset` — `FxImportList`, только Editor) делает очищенные копии эффектов `Import/FX` в `Art/Effects/<пак>/` (подробно — [PurgeMenu.md](../PurgeMenu.md)); шейдер мешей Arsenal — `Purge/ParticleRim` (неосвещённый rim). Привязка — у контента: модуль оружия `WeaponEffectsModule` («Effects»: `MuzzleFlash`; `WeaponDefinition.Effects`), `Look` у `ExplosionEffect` и `ExplosiveAttack` (оба — `IExplosionLook`); пусто — умолчание `CombatVisualDefinition`: `MuzzleFlashOf(WeaponHold)` (список `MuzzleFlashes`; стойки нет — своя вспышка `MuzzleFlash`), `ExplosionOf(radius)` (`ExplosionSmall`/`ExplosionLarge`, порог `LargeExplosionRadius`). События `BulletSystem.Exploded`/`EffectSystem.Exploded` — `(точка, радиус, IExplosionLook)`. Показ — `PackEffectsPlayer` (шаг `BuildVisuals`, перед `CombatViewPresenter`): при загрузке грузит умолчания и эффекты оружия уровня, пула дропа, базового оружия, метательного пула и слота — по `PoolSize` = 6 экземпляров на вид (все заняты — перезапускается самый старый), прогрев одного; не загруженный при старте эффект не показывается (предупреждение один раз); только в видимых клетках; эффект с `CombatEffect.Radius` > 0 масштабируется под радиус взрыва. Вспышку играет `CombatViewPresenter` (иначе своя `fx_muzzle_flash`), взрыв — `WeaponEffectsView` (иначе черновые частицы). Эффекты способностей монстров — пока только умолчания по размеру (свои — Э3).
- **Эффекты оружия (этап Э2):** модуль **Effects** — ещё `Stream` (зацикленная струя), `TargetHit` (вспышка на каждой цели цепи), `BarrelSmoke` (дым после очереди); умолчания `CombatVisualDefinition`: `Stream`, `ChainHit`, `ChainBolt` (материал молнии из текстуры пака, `ChainBoltWidth`), `BarrelSmoke` + `BarrelSmokeShots` (очередь от 3 выстрелов; дробь — по числу дробин), `HitSparks` + `HitSparksCount`/`KillSparksCount`; выбор — `StreamOf`/`ChainHitOf`/`BarrelSmokeOf` (своё оружия, иначе умолчание; по типу атаки). **Струя**: `PackEffectsPlayer.Hold` каждый кадр (один экземпляр зацикленного эффекта, `CombatEffect.Looping`; дальность — временем жизни частиц: `Radius` = дальность при полной жизни, `SetLifetimeFactor`), `Release` — гаснет; держит `CombatViewPresenter` (у дула, ствол по горизонтали) от тика атаки + интервал + 0,15 с; повторный захват во время затухания продолжает излучение (`Resume`, без очистки). У струи с видом пака нет вспышки и черновое пламя `WeaponEffectsView` не рисуется; гильзы — только у пуль и снарядов. **Дым после очереди** — конец очереди (интервал + 0,12 с без выстрела) — `fx_barrel_puff` (Build Combat Effects, дым PolygonParticleFX). **Молния**: с `ChainBolt` — один квад на прыжок, текстура вдоль V, случайное зеркалирование каждый кадр; без него — черновая ломаная. **Облако дымовой гранаты** — модуль эффекта `LookEffect` («Look only», только вид, `IExplosionLook`, радиус): `EffectSystem.LookShown` → `WeaponEffectsView` → `PackEffectsPlayer`. **Массовые эффекты** — `PackEmitters` (шаг `BuildVisuals`, после `PackEffectsPlayer`): копия эффекта пака как излучатель (своё излучение выключено, мировое пространство, до 600 частиц на систему), вьюхи кормят `Emitter.Emit(точка, количество)`, системы получают долю по своей эмиссии в паке; грузит `CombatVisual.HitSparks` и `Particles` всех зон и состояний каталога контента. Искры попаданий по орде — `HitSparks` (только попадания с направлением: зоны и горение без искр); горение на монстрах — `StatusDefinition.Particles` (раз в 0,12 с на монстра); пламя на клетках — `ZoneDefinition.Particles` × `ParticlesPerSecond` на клетку × сила (`ZoneView.Tick` — на паузе не излучает; над препятствием — с высоты 0,6). Без вида пака — прежние черновые частицы. Выбрано: струя Synty `FX_FlameThrower_02` (умолчание) и её перекраски `FX_Stream_Acid/Frost/Gas` (кислотная пушка, криомёт, газомёт), вспышка цепи Arsenal `MiniExploLightningBlue`, молния — текстура Synty `PolygonParticles_Lightning_02` (`Art/Effects/fx_chain_bolt.mat`, голубой), облако — Synty `FX_Grenade_Smoke_01`, огонь клеток и горение — Synty `FX_Fire_Small_01`, искры — Synty `FX_Sparks_01`.
- Полоски HP и цифры: `CombatFeedbackView` (Presentation, шаг `SpawnZombies` после `ZombieViewPresenter`) — полоска над зомби с его попадания (`ZombieViewPresenter.DamageShown(zombie, damage, healthAfter)`, синхронно с клипом ближнего удара), держится `BarShowTime` (3 с) после последнего, «хвост» потерянного, скрыта со вьюхой зомби, у убитого — сразу; цифры (урон зомби и игроку — красные, лечение аптечкой `+N` — зелёное, у игрока — по `PlayerHealth.Changed`) появляются маленькими, растут и гаснут за `NumberLifetime` (0.6 с), подряд у одной цели — разнос вбок и ниже. Всё — один динамический меш, шейдер `Purge/Overhead` (сплошные квады + SDF-цифры), один draw call, фиксированные пулы, без Canvas и аллокаций. **Все цвета, размеры и тайминги — `CombatVisualDefinition.Feedback` (`CombatFeedback`)**; атлас цифр и материал — **Purge → Dev → Build Damage Numbers** (`DamageNumbersBuilder`, вырезает глифы из `UiStyle.BoldFont`). Цвета палитры — sRGB, в вершины пишутся в Linear.
- Зоны зрения и шум (только вид, `VisualTheme.Awareness` / `ThemeAwareness`): `VisionZonesView` — у Walker конус, у Hunter круг, веер лучей `VisionZoneShape` (`GridRaycast` + `LevelOpacity`, как геймплейный LOS), меш на зомби пересобирается при движении/повороте/смене двери не чаще 10 раз/с; жёлтая в покое, красная в Alert, нет в погоне/атаке и у невидимых игроку зомби; рисуется целиком поверх тумана. `NoiseWavesView` — волны `Purge/Ring` до радиуса звука из `SoundEventBus` поверх всего; шаги и автоматический огонь — одно кольцо при начале ходьбы/очереди (растёт от игрока и гаснет, снова — после тишины `RingRearm`). Материалы — **Purge → Dev → Build Awareness Visuals**.
- Следы: `FootprintsView` (Presentation) по `VisualTheme.Footprints` (`ThemeFootprints`) — отпечатки игрока и зомби из геймплейных позиций (у зомби и вне видимости), логика `FootprintField` (шаг, лево/право, затухание по расстоянию до ходока и возрасту, кольцевой буфер), один динамический меш под туманом (очередь 2005, видимость = `FogMask`/`IsRevealed`), пыль — одна система частиц с `Emit`. Ассеты — **Purge → Dev → Build Footprints**. Animator игрока — параметры `PlayerAnimatorParameters` (каждый необязателен); модель Synty + клипы `Player_*` собирает **Purge → Dev → Build Player Animations** (Humanoid, root motion запечён, правки контроллера — в билдер). Клипы (этап 4а) — Ultimate Animation Collection, набор на `WeaponHold` (`PlayerAnimationsBuilder.Sets`: Unarmed, Pistol, Rifle, Shotgun, Heavy — Minigun, Shoulder — Bazooka, Melee — 1h; MeleeHeavy пока = Melee): стойка с прицелом, бег в 8 направлениях, выстрел, перезарядка / атаки A–C; удар, смерть; из Maze только `Player_use`. Недостающие клипы билдер один раз копирует из пака в `Import` → `Art/Animations/Player_<набор>_<действие>.fbx`. Базовый слой — 2D Freeform Directional на набор по `MoveX`/`MoveY` (движение относительно показанного корпуса × скорость: ноги бегут по движению, корпус — к прицелу), `Weapon` = `PlayerAnimatorParameters.SetOf(hold)`; слой `UpperBody` — выстрел (`ShootSpeed` = 1 / интервал), перезарядка, атаки своего набора, удар, Use. `Grip_L` оружия меряется по стойке его набора (`PlayerAnimationsBuilder.GripPoseClip`).

## Метательное, зоны, состояния, дроп (этап 4б)
- **Метательное** — контент `ThrowableDefinition` (`Data/Throwables`: редкость, стопка, дальность, скорость, высота дуги, интервал + список `EffectModule` — что происходит при приземлении); слот — `ThrowableSlot` (один тип, свой тип складывается, другой заменяет). `PlayerThrowing` (тик **до** `PlayerCombat`): Throw — прицел; удержание ≥ `HoldTime` и отпускание — бросок; короткое нажатие — прицел до тапа по игре (телефон) или клика (ПК: клик бросает, а не стреляет — `ConsumedAttack`), повтор — отмена. Цель: мышь / правый стик (наклон = дальность) / ближайший монстр впереди / клетка впереди; `Clamp` — центр клетки, в пределах дальности, короче первого `BlocksBullets` на прямой. Полёт — пуля `BulletSystem` с `Throwable` (над монстрами, стена — падает перед ней; `Progress`/`Travel` для дуги), при `Ended` — `EffectSystem.Apply`. Вид: `ThrowAimView` (точки дуги + кольцо радиуса эффекта, материалы `CombatVisualDefinition.ThrowArc/ThrowTarget`), летящая модель — `DropViewPresenter`, анимация — триггер `Throw` (UAC `ThrowGrenade1Standing`, слой UpperBody).
- **Эффекты** (`Core/Effects`, общие для метательного, позже — ударов и способностей): `ExplosionEffect` (`CombatTargets.Blast`: урон к краю меньше, стены укрывают; звук `SoundType.Explosion`), `PlaceZoneEffect` (`ZoneSystem.PlaceArea`), `AreaStatusEffect` (`StatusSystem.ApplyInRadius`). `EffectSystem` — события `Exploded`, `ZonePlaced`. **Враждебные** (`hostile: true` — эффекты монстров: снаряды, удар по площади, смерть; 5д1): взрыв ранит ещё и игрока (меньше к краю, стены закрывают), зона — монстров, состояние в радиусе — только на игрока; `GodMode` орды бережёт игрока. Броня монстров спереди — `CombatTargets.Damage` по направлению удара (зоны и состояния бьют без направления — `Vector2.zero`), см. Monsters.md «Элита».
- **Зоны** — `ZoneDefinition` (`Data/Effects`; модули `ZoneDamage`, `ZoneStatus`, `ZoneSpread`; цвета — черновой вид). `ZoneSystem` (после орды): массивы на все клетки всех этажей (вид, время, сила, шаги распространения, «враждебная»), список активных, `TicksPerSecond` = 8, не больше `MaxCells` = 768. Наложение той же зоны — дольше + сильнее (без суммы), другой — заменяет (комбинации — позже). Зона только там, где может быть пуля (не стены/деревья/камни/закрытые двери). Распространение — на соседние `Flammable` до `MaxSteps`. Урон — монстрам в клетке через `CombatTargets`; игроку — только враждебная (монстров). Вид — `ZoneView`: на вид зоны маска W×H + квады видимых клеток, `Purge/FireCells` (`CombatVisualDefinition.ZoneCells`) с цветами из MPB; с Э2 — ещё частицы пака (`ZoneDefinition.Particles`). **Огнемёт поджигает клетки** (Э2) — модуль оружия `IgniteCellsModule` («Ignite cells»: зона, длительность, сила; `WeaponDefinition.Ignite`): каждый тик струи `PlayerCombat` ставит зону на **горючие** (`Flammable`) клетки в конусе и дальности, до которых долетит пуля (своя клетка — всегда); голый пол не горит; дальше огонь распространяется сам. Есть у `FlameGun` (`Zone_Fire`, 4 с).
- **Состояния** — `StatusDefinition` (модули `DamageOverTimeStatus`, `StunStatus`, `SlowStatus`). `StatusSystem` (после орды): секунды на (вид, монстр), повтор — дольше, урон раз в 0,25 с через `CombatTargets`, скорость/оглушение — `HordeSystem.SetModifiers` (оглушённый не ходит и не бьёт, в виде — idle), новый монстр в слоте чистый (`HordeSystem.Generations`). Источники: зоны, эффекты, модуль оружия `StatusOnHitModule` (через `CombatTargets.WeaponHit`).
- **Состояния на игроке (5в)** — `PlayerStatusSystem` (Gameplay/Effects, тикает первым — до оружия и движения): те же `StatusDefinition`; повтор — дольше; урон раз в 0,25 с в `PlayerHealth`; скорость → `PlayerSystem.StatusSpeed`, оглушение → `PlayerSystem.Stunned` (не ходит, не стреляет, не бросает). **Иммунитет к контролю**: контроль (сейчас — оглушение; позже заморозка, окаменение, притягивание) не продлевается, пока держит, и `ControlImmunity` 2,5 с после него не берётся (замедление — не контроль). Зона монстров под игроком (`ZoneSystem.IsHostileAt`) вешает своё состояние 8 раз в секунду. В `HordeSystem.GodMode` (стресс-тест, песочница) ни урона зон, ни состояний. Вид — `PlayerStatusView`: кольцо под игроком цветом самого долгого состояния и бледное пульсирующее — пока иммунитет (`CombatVisualDefinition.StatusRing`, `Purge/Ring`). Источники — способности монстров (`MonsterAbilities`, Monsters.md) и их зоны.
- **Дроп** — `DropTable` (`Data/Drops/HordeDrop`): веса вида (пусто/патроны/аптечка/метательное/оружие), умные патроны (`HeldShare` — к оружию в слотах, больше к активному и к тому, у кого запас < 2 магазинов; количество — доля магазина), аптечки с весами (при полном HP × `MedkitAtFullHealth`), веса редкости + `MaxRarity`, жизнь и лимит на земле. `DropPool` (шаг `InitializeSystems`: что может выпасть на уровне — сейчас списки песочницы `StressTestDefinition.Drop/SandboxWeapons/SandboxThrowables`; базовый пистолет исключён), `DropRoller` (чистая функция), `DropSystem` (`HordeSystem.Killed` — смерть от чего угодно). Оружие в слотах повторно не выпадает.
- **Вид дропа** — `ItemVisualCatalog` ("Items/Visual", грузит `SharedDefinitionsService`, необязателен): пикап-префаб и летящий на определение (метательное, аптечки, патроны, оружие — пикапы Weapon Set). `DropViewPresenter` (шаг `BuildVisuals`) грузит виды всего, что может дать пул (+ все типы патронов), пулит заранее, показывает в видимых клетках, мигает последние 5 с. Собирает **Purge → Dev → Build Items**. `PickupViewPresenter` дроп не трогает.
- HUD: слот метательного на ПК (`HudScreen._throwSlot`, клавиша G) и сектор кластера (`TouchAttackCluster._throw`, `<Gamepad>/leftTrigger`) — `WeaponSlotState` (Magazine = стопка, Ammo = количество, Active = прицел), иконка — силуэт пикап-модели (`ItemVisualDefinition.Icon`, Build Items / Build UI Icons). Слоты ПК — «патроны/запас», R у обоих. Звуки — `AudioCatalog.Throw/Pin/Land/ExplosionOf(радиус)/Ignite/PickupAmmo/PickupThrowable`, петля огня `FireLoop` (ближайшая горящая клетка).
