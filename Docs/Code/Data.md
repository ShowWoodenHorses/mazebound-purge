# Фундамент данных: этажи, флаги клеток, id контента, модули, сейв

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Фундамент данных (этап 3)
- **Этаж** — часть `GridPosition` (`(x, y, Floor)`, по умолчанию 0; `OnFloor`, `ToWorld` поднимает на `FloorHeight` = 3). Этажи — слои одного W×H: индекс клетки `(floor·H + y)·W + x` (этаж 0 сохраняет индексы старых уровней), `LevelGeometry/LevelGrid.FloorCount/FloorSize`, `CellCount` = все этажи.
  - Обзор, лучи и локальный поиск работают в пределах этажа. `FlowField(LevelGrid)`, `NoiseField` с сеткой и `KeyDoorSolver` используют лестницы. Остальные варианты работают на одном этаже: старта/цели (`GridPathfinder`, `GridBfs`, `FlowField.Floor`, `FieldOfView.Floor`, `KeyDoorSolver`) или явного `floor` (`GridLineOfSight/GridRaycast`, `LightField`, `CellBuckets`, маски вида: `CellVisibilityMask`, `FogMask`, `SnowdriftMask`, `GeometryBuilder.Build`, `MapRenderer`).
  - Маски `CellMaskPassability/Opacity` — с индексацией сетки (длина = число этажей). Этаж у акторов: `PlayerSystem.Floor`, `ZombieRuntime.Floor`, `ISpatialObject.Floor` (умолчание 0), `Bullet.Floor`, `SoundEvent.Floor` (на другом этаже не слышно), запросы `ISpatialQueryService` — с `floor`.
  - `LevelGeometry.Stairs` хранит марши 1×2 между соседними этажами. `LevelGrid.TryGetStairDestination` связывает площадки перед торцами. Клетки марша блокируют обычное движение, на верхнем этаже они образуют проём (`Void`). `GroundFloor` равен 1 при подвале и 0 на старых уровнях. `CellType.Void` проходимость блокирует, пули и обзор пропускает, визуала нет.
  - новый этаж — весь Void (`LevelEditing.AddFloor/RemoveTopFloor` — только верхний, номера не сдвигаются).
- **Флаги клеток** — `CellFlags` (`BlocksMovement`, `BlocksBullets`, `BlocksSight`, `Slows`, `Flammable`; `Solid` = стена) = структура (`CellType`) | поверхность (`CellSurface`) | **препятствие** (`ObstacleDefinition`, `Data/Obstacles`: Tree — движение+пули, Bush — движение+горит, Stone — только движение (7а), Rock — всё) — `CellRules`, запекает `LevelGrid` (`GetFlags/Has`, вне сетки — `Solid`; в редакторе то же — `LevelGeometry.GetFlags`).
  - Дверь — динамика поверх флагов (закрытая блокирует всё). Препятствия хранятся в `LevelGeometry` (`_obstacleTypes` — палитра уровня, `_obstacles` — byte на клетку, 0 = нет; неиспользуемые типы выбрасываются), только на Floor (`LevelEditing.SetObstacle`, кисть **Obstacle**, Erase/смена типа снимают).
  - Системы спрашивают флаги, не `CellType`: `LevelPassability` (BlocksMovement + дверь), `LevelOpacity(grid, doors, blockers = BlocksSight)` / `LevelOpacity.ForBullets` (пули, гранаты, ближний бой, автонаведение — `IsClear(..., CellFlags.BlocksBullets, floor)`), зрение зомби — `BlocksSight`.
  - Поверхности `CellSurface`: `Snowdrift` (`Slows`), `Grass` (`Flammable`, 7а; кисть **Grass**, шаг генератора `GrassStep`), `Ground` (7г: без флагов — вид и шаги; кисть **Ground**, шаг `GroundStep`).
  - Замедление препятствия — `ObstacleSpeedFactor` (× сугроб у игрока/зомби). Вид препятствия — вариант набора Decor с `Definition` = препятствие (`VisualAssigner.ChooseDecor`; авто-декор берёт только варианты без Definition).
  - Валидатор: `ObstaclesOutOfSync`, `ObstacleNotOnFloor`, `ObjectInBlockedCell`, `ObstacleWithoutVisual`, `FloorOverhang`.
- **Стабильные id контента** — база `ContentDefinition` (`Core/Content`: `Id`, поле `_id` с `[StableId]` — только чтение в инспекторе): `WeaponDefinition`, `ZombieDefinition` (Maze), `MonsterDefinition` (этап 5, [Monsters.md](Monsters.md)), `ObstacleDefinition`, метательное, аптечки, состояния, зоны, дроп
  - новые виды контента наследуют её. Id делается один раз из имени файла (`ContentIds.FromName`: слова через `_`, латиница/цифры; занят → `_2`) — `ContentIdAssigner` (AssetPostprocessor) при создании/копии/импорте; переименование файла id не меняет.
  - Каталог — `ContentCatalog` (`Data/Content/ContentCatalog.asset`, Addressable `"Content/Catalog"`, Purge Shared; `Find/Find<T>/GetAll<T>`; собирает **Purge → Dev → Build Content Catalog** и Build/Sync), грузит `SharedDefinitionsService.Content`.
  - Строковая ссылка на контент — `[ContentRef(typeof(T))]` (выпадающий список, `ContentRefDrawer`), например `ZombieVoice.ZombieId`.
- **Модули** (`Core/Modules`): база `ContentModule` (`Validate(problems)`), у семейства — свой абстрактный наследник; контент держит `[SerializeReference, ModuleList] List<Семейство>`.
  - Инспектор любого `ContentDefinition` (`ContentDefinitionEditor`) рисует такие списки коробками с ▲▼✕ и меню **Add module** (классы семейства — `ModuleTypes.Concrete`, имя/категория/`AllowMultiple` — `[ModuleInfo]`).
  - Запросы — `Modules.TryGet(list, out T)`, `Has<T>`, `GetAll`, проверка — `Modules.Validate` (потерянный модуль, повтор, свои проблемы). Переименование класса модуля — только с `[MovedFrom]`. Конкретных модулей пока нет — этап 4 (оружие).
- **Подготовка (11б)**: `WeaponDefinition.StartPool` / `ThrowableDefinition.StartPool` — открыто без покупки (модель `start_pool`; граната). **Бустеры** — `BoosterDefinition` (Core/Boosters, `Data/Boosters`, **Purge → Dev → Build Boosters**): `Unlock` (`FirstLevel` — после первого прохождения 1-го уровня каталога, `Tree` — `SaveData.Boosters`, 11д), `Icon`, цены `BoosterPrice` (локация × 4 сложности из `boosters.csv`; 0 — не продаётся там), модули `BoosterModule`: `ThrowablesBoost`, `StartCardBoost`, `MedkitBoost`, `RerollBoost`, `ScoutingBoost`; тексты `booster.<id>`, `booster.<id>.text`.
  - `Application/Meta/RunPreparation`: открытое для старта (куплено `IProgressService.Owns` или `StartPool`) в пределах `StartRarity` (серое до ствола 11д), бустеры и их цены.
- **Сейв v1** (`SaveData.SaveVersion` = 1; формат Maze без этого поля — сохраняются только настройки): `Money`, `Levels` (`LevelRecord`: `CompletedMask` — бит на сложность, `ClosedArenaMask`; `Stars`/`BestTime` убраны в 6г — старые сейвы их просто игнорируют; запись = уровень открыт), `Survival` (лучшие очки/волна по локации), `Arsenal` (`OwnedItem`: id, уровень, `Forks` — биты выбора развилок, `PoolMark` ★/обычное/⊘), `CharacterNodes`, `Boosters` (открытые бустеры, 11а), `Loadout` (`LoadoutSave`: последняя подготовка — оружие слота 1, метательное, бустеры; `ProgressService.Loadout/SaveLoadout`; при слиянии остаётся своя), `Stats` (убийства, забеги начаты/выиграны), `Run` (`RunSave`: забег для «Продолжить» — режим, уровень, сложность, арена, seed, волна + «волна идёт», бустеры, `FreeRerolls`, `StartMedkitTaken` (11б), деньги/очки/убийства/опыт/уровень/HP/воскрешения (`AdReviveUsed`/`SkillReviveUsed`)/время забега, карточки (id на каждый уровень), бустеры, 2 слота `RunWeapon` (пусто = пистолет) и `ActiveSlot`, метательное; пишет `ProgressService.SaveRun` (6д); `Clear()`), `Settings`.
  - `Normalize` чистит пустые/повторы/отрицательные, `MergeFrom` (вход в аккаунт) — максимум/объединение, деньги — максимум (не сумма), забег и настройки — текущие. `ProgressService.RecordRun(level, result, difficulty, arenaClosed)` (победа с закрытой ареной — бит в `ClosedArenaMask`), `SpendMoney`, `IsCompleted`, `IsCompletedOn`, `IsDifficultyOpen` (лёгкая — у открытого уровня, следующая — после прохождения предыдущей; `LevelRecord.IsDifficultyOpen`); первые прохождения — `CompletedMask`. Классы записей — `Application/Save/SaveRecords.cs`.

## Персонаж и сейв забега (11д)

- С 15б `RunSnapshot.Smoke` / `RunSave.Smoke` сохраняют центр, этаж, радиус и оставшееся время каждого дымового облака на чекпоинте. Старые сейвы продолжаются без облаков.

- `SaveData.CharacterNodes` хранит покупки. При сбросе `CharacterResetGeneration` растёт, облачное слияние игнорирует сброшенную версию веток и объединяет допуски ствола.
- `RunSnapshot` и `RunSave` фиксируют флаги навыков, изгнанную карточку, остаток щита и резервы патронов, награды охотника, состояние груза и дополнительное время колпака. Поля открываются с пустыми или нулевыми значениями в сейвах до 11д.

## Данные Арсенала (11в)
- `WeaponDefinition`: `PurchasePrice`, `UniqueReward`, `ArsenalClass`; `ThrowableDefinition`: `PurchasePrice`. Поля редактируются в инспекторе. **Build Arsenal** переносит цены/уникальность из `Tools/Balance/Model/prices.csv` и `throwables.csv`; runtime CSV не читает. Класс новых предметов назначается в данных, новые id руками не вводятся.
- Стартовые предметы считаются открытыми, даже если записи в `SaveData.Arsenal` ещё нет. `OwnedItem` появляется при покупке или установке отметки. Купленный предмет определяется по стабильному id, а не ссылке на SO.

- **11г:** Weapon/ThrowableDefinition содержат `_upgradeCosts` (цены перехода на уровни 2–10/2–5), `UpgradeCost(targetLevel)` возвращает 0 для отсутствующего уровня. Импорт — Build Arsenal; OwnedItem.Level/Forks сохраняют покупку и выбор.
- RunWeapon.Shots сохраняет счётчик выстрелов; старые сейвы получают 0. WeaponDefinition хранит кривую урона, развилки и параметры эффектов; ThrowableDefinition — кривые урона/радиуса/стопки и флаг запрета прокачки.
- **Выживание (16а)**: `RunSave.Mode` восстанавливает режим через `RunSnapshot.Survival`. `SurvivalRecord.LocationId` — имя `LevelLocation` в нижнем регистре. При слиянии вся пара «очки, волны» приходит из одного забега. При равных очках выбирается большее число завершённых волн.
