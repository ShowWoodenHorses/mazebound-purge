# Фундамент данных: этажи, флаги клеток, id контента, модули, сейв

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Фундамент данных (этап 3)
- **Этаж** — часть `GridPosition` (`(x, y, Floor)`, по умолчанию 0; `OnFloor`, `ToWorld` поднимает на `FloorHeight` = 3). Этажи — слои одного W×H: индекс клетки `(floor·H + y)·W + x` (этаж 0 сохраняет индексы старых уровней), `LevelGeometry/LevelGrid.FloorCount/FloorSize`, `CellCount` = все этажи. Алгоритмы по клеткам работают **в пределах этажа**: старта/цели (`GridPathfinder`, `GridBfs`, `FlowField.Floor`, `FieldOfView.Floor`, `KeyDoorSolver`) или явного `floor` (`GridLineOfSight/GridRaycast`, `LightField`, `CellBuckets`, маски вида: `CellVisibilityMask`, `FogMask`, `SnowdriftMask`, `GeometryBuilder.Build`, `MapRenderer`). Маски `CellMaskPassability/Opacity` — с индексацией сетки (длина = число этажей). Этаж у акторов: `PlayerSystem.Floor`, `ZombieRuntime.Floor`, `ISpatialObject.Floor` (умолчание 0), `Bullet.Floor`, `SoundEvent.Floor` (на другом этаже не слышно), запросы `ISpatialQueryService` — с `floor`. Лестниц, перехода и показа других этажей нет (этап 8): вид и схема Level Designer показывают этаж 0, орда стресс-стенда живёт на этаже игрока. `CellType.Void` — нет земли (верх вне здания): не проходима, пули и обзор проходят, не рисуется; новый этаж — весь Void (`LevelEditing.AddFloor/RemoveTopFloor` — только верхний, номера не сдвигаются).
- **Флаги клеток** — `CellFlags` (`BlocksMovement`, `BlocksBullets`, `BlocksSight`, `Slows`, `Flammable`; `Solid` = стена) = структура (`CellType`) | поверхность (`CellSurface`) | **препятствие** (`ObstacleDefinition`, `Data/Obstacles`: Tree — движение+пули, Bush — движение+горит, Rock — всё) — `CellRules`, запекает `LevelGrid` (`GetFlags/Has`, вне сетки — `Solid`; в редакторе то же — `LevelGeometry.GetFlags`). Дверь — динамика поверх флагов (закрытая блокирует всё). Препятствия хранятся в `LevelGeometry` (`_obstacleTypes` — палитра уровня, `_obstacles` — byte на клетку, 0 = нет; неиспользуемые типы выбрасываются), только на Floor (`LevelEditing.SetObstacle`, кисть **Obstacle**, Erase/смена типа снимают). Системы спрашивают флаги, не `CellType`: `LevelPassability` (BlocksMovement + дверь), `LevelOpacity(grid, doors, blockers = BlocksSight)` / `LevelOpacity.ForBullets` (пули, гранаты, ближний бой, автонаведение — `IsClear(..., CellFlags.BlocksBullets, floor)`), зрение зомби — `BlocksSight`. Замедление препятствия — `ObstacleSpeedFactor` (× сугроб у игрока/зомби). Вид препятствия — вариант набора Decor с `Definition` = препятствие (`VisualAssigner.ChooseDecor`; авто-декор берёт только варианты без Definition). Валидатор: `ObstaclesOutOfSync`, `ObstacleNotOnFloor`, `ObjectInBlockedCell`, `ObstacleWithoutVisual`, `FloorOverhang`.
- **Стабильные id контента** — база `ContentDefinition` (`Core/Content`: `Id`, поле `_id` с `[StableId]` — только чтение в инспекторе): `WeaponDefinition`, `ZombieDefinition` (Maze), `MonsterDefinition` (этап 5, [Monsters.md](Monsters.md)), `ObstacleDefinition`, метательное, аптечки, состояния, зоны, дроп; новые виды контента наследуют её. Id делается один раз из имени файла (`ContentIds.FromName`: слова через `_`, латиница/цифры; занят → `_2`) — `ContentIdAssigner` (AssetPostprocessor) при создании/копии/импорте; переименование файла id не меняет. Каталог — `ContentCatalog` (`Data/Content/ContentCatalog.asset`, Addressable `"Content/Catalog"`, Purge Shared; `Find/Find<T>/GetAll<T>`; собирает **Purge → Dev → Build Content Catalog** и Build/Sync), грузит `SharedDefinitionsService.Content`. Строковая ссылка на контент — `[ContentRef(typeof(T))]` (выпадающий список, `ContentRefDrawer`), например `ZombieVoice.ZombieId`.
- **Модули** (`Core/Modules`): база `ContentModule` (`Validate(problems)`), у семейства — свой абстрактный наследник; контент держит `[SerializeReference, ModuleList] List<Семейство>`. Инспектор любого `ContentDefinition` (`ContentDefinitionEditor`) рисует такие списки коробками с ▲▼✕ и меню **Add module** (классы семейства — `ModuleTypes.Concrete`, имя/категория/`AllowMultiple` — `[ModuleInfo]`). Запросы — `Modules.TryGet(list, out T)`, `Has<T>`, `GetAll`, проверка — `Modules.Validate` (потерянный модуль, повтор, свои проблемы). Переименование класса модуля — только с `[MovedFrom]`. Конкретных модулей пока нет — этап 4 (оружие).
- **Сейв v1** (`SaveData.SaveVersion` = 1; формат Maze без этого поля — сохраняются только настройки): `Money`, `Levels` (`LevelRecord`: `CompletedMask` — бит на сложность, `ClosedArenaMask`, временно `Stars`/`BestTime` до итога этапа 6; запись = уровень открыт), `Survival` (лучшие очки/волна по локации), `Arsenal` (`OwnedItem`: id, уровень, `Forks` — биты выбора развилок, `PoolMark` ★/обычное/⊘), `CharacterNodes`, `Stats` (убийства, забеги начаты/выиграны), `Run` (`RunSave`: забег для «Продолжить» — режим, уровень, сложность, арена, seed, волна + «волна идёт», деньги/очки/убийства/опыт/уровень/HP/воскрешения забега, карточки, бустеры, 2 слота `RunWeapon`, метательное; `Clear()`), `Settings`. `Normalize` чистит пустые/повторы/отрицательные, `MergeFrom` (вход в аккаунт) — максимум/объединение, деньги — максимум (не сумма), забег и настройки — текущие. `ProgressService.RecordCompletion(level, result, difficulty = 0)`, `IsCompleted`. Классы записей — `Application/Save/SaveRecords.cs`.
