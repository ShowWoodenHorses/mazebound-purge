# Орда, песочница, стресс-тест

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

Монстры разбиты на справочники: [Zombies.md](Zombies.md) — зомби Maze · [Monsters.md](Monsters.md) — данные, вид рядовых, восприятие, сложность · [Abilities.md](Abilities.md) — способности, офицеры, Громила, двери, масса · [Elite.md](Elite.md) — элита, чемпионы, эффекты монстров · [Horde.md](Horde.md) — орда, песочница, стресс-тест.

## Орда уровня и волны (этап 6а)
- **`HordeDefinition`** (Core/Horde, `LevelData.Horde`, ассеты `Data/Horde/*Horde.asset`) — монстры любого уровня: `Monsters` (`HordeSpawn`: вид + вес — держится полной по весу только на dev-уровнях), `OnDemandMonsters`, `Waves`, виды `MonsterVisuals`/`MonsterViews` (Build Monsters — для каждого `HordeDefinition` в `Data/Horde`), `MaxAlive` (300) + `ReserveSlots` (64), `Difficulty` по умолчанию, восприятие (`WanderGroups`), `Champions`, дроп `Drop` + `PoolWeapons`/`PoolThrowables` (до покупок этапа 10).
  - `AllMonsters()` — все виды орды (по весу, волн, по запросу): из них `HordeSystem.KindList`, виды Build Monsters, эффекты `PackEffectsPlayer`. `StressTestDefinition` — только dev: стресс-оружие, счётчики `Monster Counts`/`StartCount`, дистанции появления, камера, бенч, песочница (`SandboxWeapons/Ammo/Throwables`).
  - `HordeSystem`: `Horde` (данные), `Stress` (dev, может быть null), `Difficulty` (`LevelLaunchOptions.Difficulty`, иначе орды), `MaxCount` (= `MaxAlive`, у стресса — наибольший из счётчиков), ёмкость = `MaxCount + ReserveSlots`. Без `Stress` орда стартует пустой и не пополняется сама; HP × `Difficulty.Health`.
  - `SpawnEmerging(центр, вид, радиус)` — монстр вылезает (`EmergeTime` вида) на достижимой клетке рядом, восприятие — по виду, может стать чемпионом; `FlowDistance(x, y)`.
- **Волны** — `WaveScenario` (Core/Waves, `Data/Waves`, меню Purge/Definitions/Wave Scenario): `Waves` (`WaveDefinition`: `Budget`, `Monsters` — `WaveMonster` вид + вес, `Groups` — `WaveGroup` вид × число на секунде из точки, `SpawnTime`, `PackSize`, `MaxAlive`), `PauseTime` (20 с), `FirstDelay`.
  - `WaveGenerator.Generate(волна, сложность, seed)` → `WaveSpawn` (время, вид, пачка, точка): бюджет × `Difficulty.Count` тратится по весам (старшие ранги × `SeniorShare`) только на то, что ещё влезает (`MonsterDefinition.Cost`: 0 = по рангу 1 / 10 / 30 / 100); пачки по `PackSize` равномерно по `SpawnTime` (первая сразу); группы сверху (число × `Count`, не меньше 1). Детерминирован: `SeedOf(seed забега, номер волны)`.
  - `WaveSystem` (Gameplay/Waves, шаг `SpawnZombies` и тик после орды; активна при `HordeSystem.UsesWaves` — есть волны и нет `StressTest`): фазы `Delay` → `Running` → `Pause` → … → `Completed`; `Seed` (`LevelLaunchOptions.Seed`, иначе `Environment.TickCount`), `WaveIndex`, `TimeLeft`, `PendingCount`, события `WaveStarted`/`WaveCleared`/`Completed`, `StartNextWave()`, `Skip()` (ниже).
  - Появление: пачке — одна точка `LevelData.MonsterSpawns` на этаже игрока (заданная группой или случайная), не ближе `MinPlayerDistance` (8) к игроку и достижимая; все близко — самая дальняя; точек нет — случайная достижимая клетка вдали (предупреждение). Монстр — в радиусе `SpawnRadius` (2), до 8 за тик, пока живых меньше `MaxAlive` волны.
  - **Пауза (6б)**: `Skip()` — только в `Pause` (не в `Delay`): платит `SkipBonus` = ⌈`TimeLeft`⌉ × `WaveScenario.SkipRateOf(следующая)` (`WaveDefinition.SkipRate`, 0 = номер волны) × `Difficulty.Money` в `RunWallet`, событие `Skipped`, старт волны; `StartNextWave()` — без бонуса (тесты). `RemainingCount` = живые + ещё не появившиеся, `PauseElapsed`.
  - При старте волны > 0 — `PickupSystem.ClearDropped()` (дроп волны исчезает). На уровне с волнами `DropSystem` кладёт дроп без срока жизни.
- **`RunWallet`** (Gameplay/Run, шаг `SpawnZombies`): деньги забега — `HordeSystem.Killed` → `MonsterDefinition.Money` (0 = по рангу 1/5/20/100) × `Difficulty.Money`, дробная часть копится; `Add`, `Changed`. В сейв — 6г/6д.
  - Волна кончается, когда всё появилось и живых нет (поднятые Шаманом тоже считаются); последняя → `WavesClearedRule` (как `AllKilledRule`, резолвится в `LevelSessionFactory`) → `LevelRuntime.Finish(Completed)`. `WaveSystem` не зависит от `LevelRuntime` (цикл в VContainer: рантайм получает список тиков).
- **Dev-уровень забега `Level_Run`** — **Purge → Dev → Build Run Level** (основной каталог, PLAY): поле 60×60 со столбами, 6 точек (углы, края запад/восток), AK-74 и дробовик к югу от старта; `RunHorde` (лес + общие, дроп и чемпионы песочницы) и `Data/Waves/Run.asset` (5 волн, ~5 мин) создаются один раз, дальше правятся руками.

## Орда и стресс-тест (этап 2)
- **Боевая песочница (этап 4а):** `StressTestDefinition.IsSandbox` (`Data/Horde/Sandbox.asset`, уровень `Level_Sandbox` 40×40 — **Build Stress Test Levels**: оружие из `SandboxWeapons` рядом к югу от старта) — орда воюет с оружием игрока: стресс-оружия, автопилота и бенчмарка нет, `CombatSandbox` выдаёт `SandboxAmmo` каждого типа и полную стопку первого метательного (кнопки оверлея SANDBOX: AMMO — пополнить, THROW — стопка следующего вида метательного), орда роняет дроп по `HordeDrop`, кусты к северу и востоку от старта (проверка распространения огня), черновой вид атак без префабов — `WeaponEffectsView` (пламя, молнии, взрывы, искры по орде, горение, оглушение; с 4в на всех уровнях — материалы `CombatVisualDefinition.BoltMaterial/EffectParticles`, иначе песочницы).
  - Строка **Percept** оверлея (5б): AllHunt, +Wander (10 бродяг в 10–20 клетках вне обзора), +Caller (то же с зовущим); счётчики Wander/hear/chase/calls/noise. К западу от старта — комната 5×5 со стенами и дверью (шум через стены и двери).
  - Стенд ощущения — панель **FEEL** справа (`FeelOverlay` из `StressController`, только песочница): переключатель и ползунок ×0–3 на `FeelChannel`, LOG. Кнопка **DEV** над оверлеем (5д1) скрывает и показывает обе панели (`StressController.ToggleOverlays`, `PlayerPrefs` `Purge.Dev.OverlaysHidden`)
  - строки Officer и Elite — вызванные монстры по рангу, подписи — короткие (`DistC`, `ShamF`). Камера по умолчанию ±7 (`TopDownCamera`), обзор — радиус 10 (`VisibilitySystem.DefaultRadius`).
- **Орда** — `HordeSystem` (Gameplay/Horde, шаг `SpawnZombies`, тик после `ZombieSystem`): монстры в плоских массивах (позиция, `Facing` в радианах 0 = North по часовой, HP, состояние `HordeAgentState`, таймеры, вид монстра и вариант материала; статы — вида, см. выше), все идут по общему `FlowField` (Core/Navigation: Дейкстра 8 направлений, орт. 2 / диаг. 3, без срезания углов; пересчёт только при смене клетки игрока или двери), расталкивание — `CellBuckets` (Core/Horde, корзины по клеткам, пересобираются каждый тик), скольжение по стенам квадратным футпринтом, атака в `AttackReach`, труп `CorpseTime`.
  - Попадания — `QuerySegment`/`QueryCone`/`FirstInCell`. Включается у уровня с `LevelData.Horde` (`HordeDefinition`, см. выше).
- **Вид орды** — `HordeRenderer` (Presentation/Visual/Horde): без GameObject, `Graphics.RenderMeshInstanced` пачками по 128 на вариант вида (`MaterialPropertyBlock` на пачку, `_HordeFrame` = кадр A, кадр B, смешивание, вспышка), отсечение по экрану и обзору, пятна-тени тем же способом.
  - Шейдер **`Purge/Horde`**: анимация из текстур — кости (2 сильнейшие, по умолчанию) или VAT (global keyword `PURGE_HORDE_VAT`), смешивание кадров `PURGE_HORDE_LERP`; нормали плоские из производных (меш сварен без нормалей).
  - Данные — `HordeVisualDefinition` (**Purge → Dev → Build Horde Visuals**: меш, текстуры, материалы, клипы по имени `Zombie_<idle|walk|run|attack|death>*`).
- **Стресс-тест**: `StressWeapons` (поток пуль, дробовик, огнемёт, `FireField` — горящие клетки), `StressEffectsView` (трассеры — динамический меш, частицы через `Emit`, огонь — маска `_PurgeFireMask` W×H + квады над горящими видимыми клетками, шейдер `Purge/FireCells`), `StressController` + `StressOverlay` (оверлей uGUI кодом, метрики, кнопки, автобенчмарк `BenchmarkPlan` → канал `GameLog` `Performance`), `StressAutopilotInput` (обёртка `IPlayerInput`, регистрируется в `LevelSessionFactory` только для стресс-уровня).
  - Уровни `Level_Stress64/100` — **Build Stress Test Levels**; сборки **… Stress Test** (release + dev-уровни, symbol `PURGE_DEV_LEVELS`). Методика и результаты — [Docs/StressTest.md](Docs/StressTest.md).
- `VisibilitySystem.SetRadius` (радиус обзора, по умолчанию 10), `LastComputeMs`; `TopDownCamera.FollowHalfExtent` — меняются в рантайме. `WebPage.SetResolutionScale` — масштаб разрешения (веб: `Module.devicePixelRatio`, Android: `Screen.SetResolution`).
- **Ловушка MCP:** не обновлять ассеты (`refresh_unity`) во время Play после правки скриптов — домен перезагрузится посреди игры, скоупы VContainer сломаются. Сначала Stop.
