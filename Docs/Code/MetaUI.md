# Карта, сейв, UI, локализация, обучение

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Карта, итог, сохранения
- **Итог (6г)**: `LevelProgress.GetResult` → `LevelResult` (победа, волны пройдено/всего — `RunScore.WavesCleared`, убийства — орда + зомби Maze, время, деньги `RunWallet`, очки `RunScore`, воскрешения). Звёзд и лучшего времени больше нет.
  - `GameFlow.EndLevel` (в т.ч. из `Death`) → `IProgressService.RecordRun` всегда (деньги и убийства; при победе — сложность, `RunsWon`, следующий уровень) → окно. `LastWasCompletedBefore` — для радостного момента и аналитики.
  - ×2: `GameFlow.CanDoubleReward` / `DoubleRewardAsync` (rewarded `result_double`, без рекламы — бесплатно) → `AddMoney` ещё раз, один раз на итог.
- **Сейв забега (6д)**: `RunCheckpoints` (Gameplay/Run, шаг `SpawnZombies` после волн) → `Reached(RunSnapshot)` на старте волны («волна идёт», без бонуса пропуска паузы) и на её зачистке (кроме последней) → `ILevelSession.RunCheckpoint` → `GameFlow` → `IProgressService.SaveRun` (сразу в PlayerPrefs, облако — с задержкой `SaveService`). `RunSnapshot` ↔ `RunSave`: `Wave` в сейве с 1, `NextWave` = волна заново, если шла.
  - «Продолжить» — `GameFlow.ContinueRun` → `LevelLaunchOptions(resume:)` (seed из сейва); `RunLoadout` (шаг `InitializeSystems`, до сбора вида) — карточки (`CardSystem.Restore`, без `Chosen`), HP, воскрешения, слоты, метательное; `RunCheckpoints` — деньги, очки, опыт, время, `WaveSystem.ResumeAt` (полная пауза перед волной). Дроп с земли не сохраняется.
  - Новый забег: seed — `GameFlow.NewSeed` (один на все системы). Выход из паузы в меню — сейв остаётся, денег в сейв нет; «Заново» из паузы и новый забег из меню при сохранённом — `AbandonRun` (деньги брошенного — в сейв). Конец забега (смерть, победа) — `ClearRun`. Уровни без волн (обучение, песочница) сейва не имеют и денег при выходе не дают.
  - UI: кнопка «Продолжить» над «Играть» (`MainMenuScreen.SetContinueAvailable`, акцент переходит на неё), `ConfirmScreen` (да/нет поверх меню и паузы, не состояние потока; `ScreenRouter.StartNewRun` спрашивает при `IsRunActive || HasSavedRun`).
- **Отклик забега (6д)**: `RunFeedbackPresenter` (шаг `InitializeUI`, уровни с волнами) — монетка с точки убийства (если на экране) к иконке денег HUD (`HudScreen.CoinLayer`, шаблон — первый ребёнок, пул 16, лишние не летят), иконка подпрыгивает, звук `Coin`; вспышка `CombatVisualDefinition.LevelUp` у игрока при повышении.
- **Окно смерти (6г)**: `GameFlowState.Death` (пауза, HUD виден) — `GameFlow.OpenDeath/CloseDeath`; `DeathPresenter` (шаг `InitializeUI`) по `PlayerRevival.Downed` → `DeathScreen` (кнопки «Воскреснуть» за rewarded `revive`, «Воскреснуть: навык», «Отказаться»; использованные скрыты). Сам механизм — [Player.md](Player.md), «Смерть и воскрешение».
- Карта (§60): `GameFlowState.Map` = пауза (`GameFlow.OpenMap/CloseMap`); ввод — событие `IInputService.MapRequested` (M/Tab/Select), `PauseController` переключает карту, Escape её закрывает; в HUD вместо кнопки «Map» — мини-карта (её `_mapButton`).
  - **Туман (7г)**: `MapExploration` (Gameplay/Visibility, шаг `InitializeVisibility` после `VisibilitySystem`) — бит на клетку всех этажей, клетки `RevealedCells` становятся исследованными навсегда, событие `Explored(новые клетки)`; в сейве забега — `RunSnapshot/RunSave.Explored` (Base64, `Pack/Unpack`; другой размер уровня — игнор), `RunCheckpoints` пишет `Export()`.
  - `MapPresenter` (Presentation/Map, шаг `InitializeUI`) владеет `Texture2D` (пиксель на клетку, этаж 0): `MapRenderer` рисует только исследованное (остальное `Unknown` — чёрное; стены, препятствия `BlocksMovement` — `Obstacle`, проходы; дверь — проход), новые клетки докрашивает `RenderCell`, загрузка в текстуру — `ApplyPending` (открытие карты, тик мини-карты).
  - Поверх — значки (`MapIconSet` в `Art/UI/MapIcons`, рисует **Purge → Dev → Build Map Icons**; правила — `MapIconLayout`, наклон/сдвиг по id): старт игрока; в исследованных клетках — двери (запертая — замок цвета пары, `VisualColorTags`), лежащие оружие/аптечки/ключи (ключ — цвет своей двери; из `PickupSystem.GetAll`) и ключ сундука; слой Objects — бочки (цвет типа), сундуки (запертый — `LockedChest`, открытый — тусклый), колпак (кольцо по `RefugeSystem.Edge`, пока стоит); монстры — только в обзоре (`VisibilitySystem.IsVisible`): орда точками `Monster` (рядовые `MonsterSize`, офицеры/элита/чемпионы/боссы `BigMonsterSize`, цвет ранга, чемпион — свой), зомби Maze — черепом.
  - игрок — всегда, последним. Число значков не растёт после загрузки (слоты по числу в уровне, орде — `MapPresenter.MonsterSlots` = 160, лишние скрыты). Обновляются при открытии карты/переключении; `AddObjectIcons`/`AddMonsterIcons` общие с мини-картой.
  - переключатели (бесплатные) — по `MapLayer` (Player, Zombies — «Монстры», Weapons, Medkits, Keys, Objects) колонкой слева от карты (вместе с картой — в контейнере `SafeArea` с `SafeAreaFitter`: фронтальная камера не перекрывает), `MapScreen.LayerChanged/SetLayer` → `SettingsService.MapShow*` (в сейве инвертированы: `MapHide*`).
  - **Стрелки на монстров за экраном (2026-10-26)**: `MonsterArrowsView` (слой HUD под текстами, свой Canvas, шаблон `ui_pointer` 26 ед., `Danger`, отступ от края 24) ← `MonsterArrowsPresenter` (шаг `InitializeUI`, `ILevelLateTickable`): 40 секторов направлений от игрока на экране, 10 раз/с в секторе — ближайший живой монстр вне экрана (туман не важен), каждый кадр стрелка переставляется по краю safe area и пропадает, как только монстр на экране; дальше края в 3 раза — бледнее (0,35). Выкл. — `GameSettings.NoMonsterArrows`.
  - **Мини-карта (7г)**: `MiniMapView` (HUD справа вверху, левее Pause, квадрат 216 — кнопка, тап — полная карта; viewport со своим Canvas и `RectMask2D`, внутри движущийся content: изображение карты + значки в клетках, стрелка игрока в центре) ← `MiniMapPresenter` (шаг `InitializeUI` после `MapPresenter`, `ILevelLateTickable`): окно `WindowCells` = 32 клетки, каждый кадр сдвигается только content, значки (объекты, монстры в обзоре внутри окна, до `MonsterSlots` = 96) и докраска тумана — `RefreshRate` = 10 раз/с; переключатели — те же, что у карты.
- Таймер: `LevelProgress` — `ILevelTickable`, `Elapsed` идёт только в Running (пауза, карта, окна — нет) → `LevelResult.Time`.
  - Показ: HUD сверху по центру (`HudScreen.SetTime`, текст меняется раз в секунду без аллокаций), строка времени итога. Формат — `TimeFormat` (m:ss, h:mm:ss), одинаковый во всех языках.
- Сейв (§85): `SaveService` (`ISaveStorage` → `PlayerPrefsSaveStorage`, ключ `Purge.SaveData`, JSON `JsonUtility`; битый → новый), `SettingsService` хранит настройки в сейве и сохраняет при изменении (регистрируется после Save), `ProgressService` (первый уровень каталога открыт, завершение на любой сложности открывает следующий, `Money`, `AddMoney`, `Stats.TotalKills`/`RunsWon`; схема — «Фундамент данных»).
  - Закрытые уровни в редакторе/dev-сборке запускаются; «Debug: reset progress» в меню.
- PlayMode-тесты, завершающие уровень, пишут настоящий `PlayerPrefs` — сохранять и восстанавливать ключ сейва (см. `Map_Icons_AndCompletionByKillingAll_SavesStars` — имя историческое).

## UI: стиль, фигуры, экраны
- Стиль (макет: Progress.md п.16) — тонкие светлые линии, тёмная полупрозрачная заливка, цвет только у важного (акцент — активное/доступное/следующее, HP, ключи), ромбы-орнаменты.
  - Всё рисуется из **`UiShape`** (`Presentation/UI/Shapes`): Rect (скругление) / Capsule / Sector (центр в долях rect, радиусы, начало и развёртка в градусах, 0 = вправо, против часовой) / Arrow (правый конец — острие, длина в `CornerRadius`)
  - заливка `Fill` и обводка `Stroke`/`StrokeWidth` (внутрь края) — в UV-каналах, `Graphic.color` — тинт поверх. Шейдер **`Purge/UIShape`** (SDF), один общий материал `Art/UI/UIShape.mat` — фигуры батчатся.
  - Клик только внутри фигуры (+`HitPadding`; он же ставит `raycastPadding` = −паддинг, иначе raycaster отсекает касания вне rect). Круглые кнопки (`RoundButton`) — запас 24 ед. порог перетаскивания EventSystem ~2 мм по dpi (`UIRoot.ScaleDragThreshold`).
  - Фигура обрезана rect-ом: rect сектора — `UiShapeMath.SectorBounds`. Формулы шейдера и `UiShapeMath` должны совпадать.
- **`UiStyle`** (`Data/UI/UiStyle.asset`, **Purge → Dev → Build UI Style**): палитра (sRGB), толщины, материал, шрифты.
  - Текст — **TextMeshPro, Rajdhani** SemiBold/Bold (OFL, `Art/Fonts/Rajdhani`) — латиница всех языков, fallback **Exo 2** SemiBold/Bold (OFL, `Art/Fonts/Exo2`, масштаб 0.96) — кириллица; статические SDF-атласы только с символами ASCII + таблицы переводов
  - билдер же делает Rajdhani шрифтом TMP по умолчанию и чистит `TextMesh Pro/Resources` от образцового шрифта и эмодзи. Кнопки, заголовки и динамичные подписи в узких рамках — с автоуменьшением TMP до 70% (`AutoSize` в билдере).
- Иконки — **`UiIconSet`** (`Data/UI/UiIcons.asset`, **Purge → Dev → Build UI Icons**): линейные иконки (сетка 24, одна толщина), фон меню `Backdrop` (процедурный лабиринт) и силуэты оружия из моделей → `WeaponVisualDefinition.Icon` (Build Weapons пересобирает их сам).
- Кнопки — **`UiButton`** (фигура + контент, состояния: hover/selected — яркая обводка, pressed — светлая заливка и 0.96, disabled — бледно; `Accent` — главное действие), переключатели — Toggle + **`UiSwitch`**, ползунки — Slider с ромбом (ручка — ребёнок `Handle`: Slider растягивает её по высоте; касание — невидимая `HitArea` на весь ползунок с запасом: тонкие фигуры ловят клик только своим rect-ом).
  - Вкладка настроек CONTROLS — только при тач-контролах (`HudScreen.TouchShown`) или в dev-сборке. Экраны появляются плавно (`UiAppear`, панель диалога «всплывает»).
- Экраны: главное меню (внизу справа — деньги с монетой и убийства; PLAY → **`LevelSelectScreen`**: по 10 уровней 5×2, `LevelPages`, страница следующего уровня, свайп, закрытые — замок и покачивание `LevelTile`; звёзд и времени нет), настройки (вкладки Controls / Shooting / Game / Other, ряды «подпись — контрол — значение» высотой 74, режимы сегментами; Game — камера, разрешение, сравнение при подборе — Player.md), панель сравнения над оружием в HUD (`PickupComparePanel`, 6е2), пауза, окно смерти (`DeathScreen`), результат (`ResultScreen`: ПОБЕДА / ПОРАЖЕНИЕ, строки «подпись — значение» волны / убийства / время / очки / заработано — по одной со звуком: `AppAudioPresenter` вызывает `RevealNextRow`, пока `PendingRows` > 0; слот строки держит место — панель не прыгает; после строк — «×2 НАГРАДА»; NEXT — следующий уровень каталога), карта, ошибка, загрузка.
  - Вёрстка — только в `RuntimeScenesBuilder` (единицы — 1920×1080 у основного канваса, 0.1 мм у тач-канваса).
- HUD: `HudScreen` (сердце, имя уровня, HP-полоса со стрелкой и «хвостом» урона, мало HP — красная пульсация; убийства, ключи цветом дверей; сообщение между ромбами; Map/Pause), слоты оружия на десктопе — `HudWeaponSlot` (без тач-контролов).
  - **Волны (6б)**: `WaveHudPresenter` (шаг `InitializeUI`, следит за `WaveSystem` из `LateTick` — волны стартуют позже) → `HudScreen`: под таймером `WaveRow` («ВОЛНА 2/5», череп — `RemainingCount`, монета `UiIconSet.Coin` — `RunWallet.Money`; числа через `SetText` без аллокаций); в `Delay`/`Pause` — `Countdown` (`hud.wave.countdown`), кнопка `SkipButton` «ПРОПУСТИТЬ +N» (только в паузе; подсказка «ПРОБЕЛ» без тач-контролов), запас патронов по типам (`ammo.<id>`, только > 0); `Banner` «ВОЛНА N» / «ВОЛНА ПРОЙДЕНА» (гаснет за 2,2 с).
    - Пропуск: кнопка или `IInputService.ConfirmRequested` (Enter/Space/South) не раньше `SkipLock` (1 с) паузы, только в `GameFlowState.Playing`.
  - **Опыт (6в)**: под HP-полосой тонкая полоса опыта акцентом и «УР. N» (`HudScreen.SetExperience`, ведёт `CardsPresenter`; скрыта без карточек). Экран карточек — `CardsScreen` ([Cards.md](Cards.md)).
  - **Дуга урона (5в)**: `PlayerHealth.Hurt(amount, source)` (удар с направлением — способности монстров) → `HudScreen.ShowDamageArc`: 4 дуги `_damageArcs` (RawImage по центру, квадрат по короткой стороне экрана, текстура дуги рисуется на старте) поворачиваются в сторону удара (север = вверх, камера не крутится) и гаснут за 0,9 с.
  - Красная пульсация краёв — только на удар ≥ 5 HP или 5 % максимума (тики кислоты/огня не пульсируют). Данные — `HudPresenter` (события + `LateTick` для слотов и цели Use: `WeaponRuntime.ReloadProgress`, `PlayerInteraction.CurrentTarget()`).

## Локализация
- Языки (13): en (базовый), ru, tr, es, de, pt (бразильский), fr, it, pl, id, kk, uz (латиница, ʻ — U+02BB), be. Новые 8 — черновой перевод агента (2026-10-11), ждут вычитки пользователем.
  - У kk/uz пустая `language.system` (в `SystemLanguage` их нет; проверка это допускает) — язык от площадки или из настроек. Исходник — **`Data/Localization/Strings.tsv`** (ключ + колонка на язык, TAB; строки `language.name`, `language.system`)
  - **Purge → Dev → Build Localization** (`LocalizationBuilder`) → `LocalizationTable` на язык (`Texts_<код>`) + `LanguageCatalog` ("Localization/Languages"), Addressable в Purge Shared (`LevelSync.SyncShared` их держит), проверка (`LocalizationCheck`: ключи `TextKeys` без строки и разные `{n}` — ошибки; неиспользуемые, непереведённые — предупреждения), затем Build UI Style (атласы под символы).
- `LocalizationService` (Application, после `SettingsService`): грузит каталог и **только выбранную** таблицу (свой owner на таблицу, старая освобождается при смене)
  - язык — `SettingsService.Language` (`SaveData.Settings.Language`; пусто → первый запуск выбирает по `Application.systemLanguage`, иначе базовый, и сохраняет). `Get(key)` без аллокаций, `Format`; непереведённое — текст базового языка, в dev-сборке/редакторе — ключ (`ShowMissingKeys`)
  - неизвестный ключ — ключ + предупреждение. `LanguageChanged` — после загрузки таблицы (и при старте).
- Ключи — константы **`TextKeys`** (Presentation) + семейства-префиксы (`weapon.<id>`, `hud.locked.<цвет>`, `layout.element.<элемент>`); новый текст = константа + строка в таблице.
  - Статичные подписи — компонент **`LocalizedText`** (ключ), ставит `RuntimeScenesBuilder` через `Loc(TextKeys.X)` в любом хелпере текста, список — `UIRoot._localizedTexts`
  - `LocalizationPresenter` → `UIRoot.ApplyLanguage` (подписи + `UIScreen.ApplyLanguage` у экранов с составными текстами, редактор раскладки).
  - Динамичные тексты — презентеры (`HudPresenter`, `MapPresenter` — перерисовка подписи при смене языка, `ScreenRouter` — «LEVEL N» по номеру в каталоге: `DisplayName` уровня игроку не показывается).
- Заглавные буквы пишутся в таблице, **никакого `ToUpper` в коде** (турецкое i/İ). Проценты — `format.percent` (tr «%50», de/es «50 %»).
  - Язык меняется в настройках (вкладка Other: кнопка с названием → выпадающий список `LanguagePicker`, языки своими названиями, текущий — акцентом, тап мимо — закрыть; пункты клонируются из одного при первом открытии) из меню и с паузы; Reset tab язык не сбрасывает.

## Обучение
- Уровень обучения — `Data/Levels/Level_Tutorial` (замок) со сценарием `TutorialSteps` (`TutorialScript`, ссылка `LevelData.Tutorial`).
  - Уровень со сценарием Build / Sync ставит в `LevelCatalog.Tutorial` (не в номерные `Levels`): кнопка **ОБУЧЕНИЕ** в меню (между Play и Settings), подпись HUD «TUTORIAL», вне прогрессии, номер 0 (реклама и аналитика). Завершение — окно «Обучение пройдено» без звёзд и времени, NEXT — первый уровень
  - провал — обычное окно. `GameFlow.IsTutorialLevel`.
- Шаг (`TutorialStep`): ключ текста `tutorial.*` (варианты `.touch`, `.hint`, `.hint.touch`; выпадающий список ключей из `Strings.tsv`), `Dialog`, `Goal` (Reach/Collect/UnlockDoor/OpenDoor/Kill/OpenMap/None), `Target` (id объекта, выпадающий список), `Cell`, `Highlight`.
  - Проверяет `LevelValidator` (`TutorialStepInvalid`) и Build Localization (ключи шагов есть в таблице).
- `TutorialSystem` (Gameplay/Tutorial, стадия `SpawnZombies` после зомби): шаг завершается **состоянием** игры, проверка — по событиям (клетка, `PickupSystem.Removed`, двери, смерть зомби, `ReportMapOpened`); выполненный заранее шаг пропускается.
  - Линии к цели нет (подсказка маршрута убрана) — только стрелка `TutorialPresenter`. Сценарий — от Maze (без шагов фрагмента и выхода); при `AllKilledRule` обучение завершается на последнем убитом зомби — переделывается в обучающий забег.
- `TutorialPresenter` (Presentation, `InitializeUI`) → `UIRoot.Tutorial` (`TutorialScreen` над HUD): окно шага через `DialogDelay` игрового времени → `GameFlow.OpenTip` (**`GameFlowState.Tip`** — пауза, HUD виден; «ПОНЯТНО», Enter/пробел/South — `IInputService.ConfirmRequested`, Esc; не раньше 0.35 с), строка-напоминание сверху, стрелка над целью (у края экрана — к цели), пульсирующее кольцо вокруг кнопки (`Highlight`: тач-элементы, карта, слоты на ПК).
  - Аналитика — `tutorial_step`.
