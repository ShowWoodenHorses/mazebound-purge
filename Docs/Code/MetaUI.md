# Карта, сейв, UI, локализация, обучение

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Карта, звёзды, сохранения
- `LevelProgress` → `LevelResult` (звёзды Maze до переделки итога на этапе 6: завершение + все зомби + бывшая звезда фрагментов, теперь всегда с завершением; без завершения 0).
- Карта (§60): `GameFlowState.Map` = пауза (`GameFlow.OpenMap/CloseMap`); ввод — событие `IInputService.MapRequested` (M/Tab/Select), `PauseController` переключает карту, Escape её закрывает; кнопка «Map» в HUD. `MapPresenter` (Presentation/Map, шаг `InitializeUI`) владеет `Texture2D` (пиксель на клетку, рисуется раз при загрузке), `MapRenderer` рисует из `LevelGrid` весь уровень (стены и проходы; дверь — проход; «исследовано» тумана — позже). Поверх — значки (`MapIconSet` в `Art/UI/MapIcons`, рисует **Purge → Dev → Build Map Icons**; правила — `MapIconLayout`, наклон/сдвиг по id): старт игрока, двери (запертая — замок цвета пары, `VisualColorTags`), живые зомби (череп; позиция на момент открытия — карта = пауза), лежащие оружие/аптечки/ключи (ключ — цвет своей двери; из `PickupSystem.GetAll`, выпавшее оружие тоже); игрок — всегда, последним. Число значков не растёт после загрузки (слоты пикапов по числу в уровне, лишние скрыты). Обновляются при открытии карты/переключении; переключатели (бесплатные) — по `MapLayer` (Player, Zombies, Weapons, Medkits, Keys) колонкой слева от карты (вместе с картой — в контейнере `SafeArea` с `SafeAreaFitter`: фронтальная камера не перекрывает), `MapScreen.LayerChanged/SetLayer` → `SettingsService.MapShow*` (в сейве инвертированы: `MapHide*`).
- Таймер: `LevelProgress` — `ILevelTickable`, `Elapsed` идёт только в Running (пауза, карта, окна — нет) → `LevelResult.Time`; лучшее — `LevelRecord.BestTime` (0 = нет; `IProgressService.GetBestTime`), `GameFlow.LastPreviousBestTime` — прежний рекорд для окна результата. Показ: HUD сверху по центру (`HudScreen.SetTime`, текст меняется раз в секунду без аллокаций), результат (время + лучшее или «новый рекорд»), плитка уровня. Формат — `TimeFormat` (m:ss, h:mm:ss), одинаковый во всех языках.
- Завершение (§89): `GameFlow.EndLevel` → `ILevelSession.GetResult` → `IProgressService.RecordCompletion` (только Completed) → окно результата (`GameFlow.LastResult`). Смерть ничего не сохраняет.
- Сейв (§85): `SaveService` (`ISaveStorage` → `PlayerPrefsSaveStorage`, ключ `Purge.SaveData`, JSON `JsonUtility`; битый → новый), `SettingsService` хранит настройки в сейве и сохраняет при изменении (регистрируется после Save), `ProgressService` (первый уровень каталога открыт, завершение на любой сложности открывает следующий, лучшие звёзды, `Stats.TotalKills`; схема — «Фундамент данных»). Закрытые уровни в редакторе/dev-сборке запускаются; «Debug: reset progress» в меню.
- PlayMode-тесты, завершающие уровень, пишут настоящий `PlayerPrefs` — сохранять и восстанавливать ключ сейва (см. `Map_Icons_AndCompletionByKillingAll_SavesStars`).

## UI: стиль, фигуры, экраны
- Стиль (макет: Progress.md п.16) — тонкие светлые линии, тёмная полупрозрачная заливка, цвет только у важного (акцент — активное/доступное/следующее, HP, ключи), ромбы-орнаменты. Всё рисуется из **`UiShape`** (`Presentation/UI/Shapes`): Rect (скругление) / Capsule / Sector (центр в долях rect, радиусы, начало и развёртка в градусах, 0 = вправо, против часовой) / Arrow (правый конец — острие, длина в `CornerRadius`); заливка `Fill` и обводка `Stroke`/`StrokeWidth` (внутрь края) — в UV-каналах, `Graphic.color` — тинт поверх. Шейдер **`Purge/UIShape`** (SDF), один общий материал `Art/UI/UIShape.mat` — фигуры батчатся. Клик только внутри фигуры (+`HitPadding`; он же ставит `raycastPadding` = −паддинг, иначе raycaster отсекает касания вне rect). Круглые кнопки (`RoundButton`) — запас 24 ед.; порог перетаскивания EventSystem ~2 мм по dpi (`UIRoot.ScaleDragThreshold`). Фигура обрезана rect-ом: rect сектора — `UiShapeMath.SectorBounds`. Формулы шейдера и `UiShapeMath` должны совпадать.
- **`UiStyle`** (`Data/UI/UiStyle.asset`, **Purge → Dev → Build UI Style**): палитра (sRGB), толщины, материал, шрифты. Текст — **TextMeshPro, Rajdhani** SemiBold/Bold (OFL, `Art/Fonts/Rajdhani`) — латиница всех языков, fallback **Exo 2** SemiBold/Bold (OFL, `Art/Fonts/Exo2`, масштаб 0.96) — кириллица; статические SDF-атласы только с символами ASCII + таблицы переводов; билдер же делает Rajdhani шрифтом TMP по умолчанию и чистит `TextMesh Pro/Resources` от образцового шрифта и эмодзи. Кнопки, заголовки и динамичные подписи в узких рамках — с автоуменьшением TMP до 70% (`AutoSize` в билдере).
- Иконки — **`UiIconSet`** (`Data/UI/UiIcons.asset`, **Purge → Dev → Build UI Icons**): линейные иконки (сетка 24, одна толщина), фон меню `Backdrop` (процедурный лабиринт) и силуэты оружия из моделей → `WeaponVisualDefinition.Icon` (Build Weapons пересобирает их сам).
- Кнопки — **`UiButton`** (фигура + контент, состояния: hover/selected — яркая обводка, pressed — светлая заливка и 0.96, disabled — бледно; `Accent` — главное действие), переключатели — Toggle + **`UiSwitch`**, ползунки — Slider с ромбом (ручка — ребёнок `Handle`: Slider растягивает её по высоте; касание — невидимая `HitArea` на весь ползунок с запасом: тонкие фигуры ловят клик только своим rect-ом). Вкладка настроек CONTROLS — только при тач-контролах (`HudScreen.TouchShown`) или в dev-сборке. Экраны появляются плавно (`UiAppear`, панель диалога «всплывает»).
- Экраны: главное меню (PLAY → **`LevelSelectScreen`**: по 10 уровней 5×2, `LevelPages`, страница следующего уровня, свайп, закрытые — замок и покачивание `LevelTile`), настройки (вкладки, ряды «подпись — контрол — значение», режим прицела сегментами), пауза, результат (звёзды по одной: `AppAudioPresenter` вызывает `ResultScreen.RevealNextStar` со звуком звезды; NEXT — следующий уровень каталога), карта, ошибка, загрузка. Вёрстка — только в `RuntimeScenesBuilder` (единицы — 1920×1080 у основного канваса, 0.1 мм у тач-канваса).
- HUD: `HudScreen` (сердце, имя уровня, HP-полоса со стрелкой и «хвостом» урона, мало HP — красная пульсация; убийства, ключи цветом дверей; сообщение между ромбами; Map/Pause), слоты оружия на десктопе — `HudWeaponSlot` (без тач-контролов). **Дуга урона (5в)**: `PlayerHealth.Hurt(amount, source)` (удар с направлением — способности монстров) → `HudScreen.ShowDamageArc`: 4 дуги `_damageArcs` (RawImage по центру, квадрат по короткой стороне экрана, текстура дуги рисуется на старте) поворачиваются в сторону удара (север = вверх, камера не крутится) и гаснут за 0,9 с. Красная пульсация краёв — только на удар ≥ 5 HP или 5 % максимума (тики кислоты/огня не пульсируют). Данные — `HudPresenter` (события + `LateTick` для слотов и цели Use: `WeaponRuntime.ReloadProgress`, `PlayerInteraction.CurrentTarget()`).

## Локализация
- Языки (13): en (базовый), ru, tr, es, de, pt (бразильский), fr, it, pl, id, kk, uz (латиница, ʻ — U+02BB), be. Новые 8 — черновой перевод агента (2026-10-11), ждут вычитки пользователем. У kk/uz пустая `language.system` (в `SystemLanguage` их нет; проверка это допускает) — язык от площадки или из настроек. Исходник — **`Data/Localization/Strings.tsv`** (ключ + колонка на язык, TAB; строки `language.name`, `language.system`); **Purge → Dev → Build Localization** (`LocalizationBuilder`) → `LocalizationTable` на язык (`Texts_<код>`) + `LanguageCatalog` ("Localization/Languages"), Addressable в Purge Shared (`LevelSync.SyncShared` их держит), проверка (`LocalizationCheck`: ключи `TextKeys` без строки и разные `{n}` — ошибки; неиспользуемые, непереведённые — предупреждения), затем Build UI Style (атласы под символы).
- `LocalizationService` (Application, после `SettingsService`): грузит каталог и **только выбранную** таблицу (свой owner на таблицу, старая освобождается при смене); язык — `SettingsService.Language` (`SaveData.Settings.Language`; пусто → первый запуск выбирает по `Application.systemLanguage`, иначе базовый, и сохраняет). `Get(key)` без аллокаций, `Format`; непереведённое — текст базового языка, в dev-сборке/редакторе — ключ (`ShowMissingKeys`); неизвестный ключ — ключ + предупреждение. `LanguageChanged` — после загрузки таблицы (и при старте).
- Ключи — константы **`TextKeys`** (Presentation) + семейства-префиксы (`weapon.<id>`, `hud.locked.<цвет>`, `layout.element.<элемент>`); новый текст = константа + строка в таблице. Статичные подписи — компонент **`LocalizedText`** (ключ), ставит `RuntimeScenesBuilder` через `Loc(TextKeys.X)` в любом хелпере текста, список — `UIRoot._localizedTexts`; `LocalizationPresenter` → `UIRoot.ApplyLanguage` (подписи + `UIScreen.ApplyLanguage` у экранов с составными текстами, редактор раскладки). Динамичные тексты — презентеры (`HudPresenter`, `MapPresenter` — перерисовка подписи при смене языка, `ScreenRouter` — «LEVEL N» по номеру в каталоге: `DisplayName` уровня игроку не показывается).
- Заглавные буквы пишутся в таблице, **никакого `ToUpper` в коде** (турецкое i/İ). Проценты — `format.percent` (tr «%50», de/es «50 %»). Язык меняется в настройках (вкладка Other: кнопка с названием → выпадающий список `LanguagePicker`, языки своими названиями, текущий — акцентом, тап мимо — закрыть; пункты клонируются из одного при первом открытии) из меню и с паузы; Reset tab язык не сбрасывает.

## Обучение
- Уровень обучения — `Data/Levels/Level_Tutorial` (замок) со сценарием `TutorialSteps` (`TutorialScript`, ссылка `LevelData.Tutorial`). Уровень со сценарием Build / Sync ставит в `LevelCatalog.Tutorial` (не в номерные `Levels`): кнопка **ОБУЧЕНИЕ** в меню (между Play и Settings), подпись HUD «TUTORIAL», вне прогрессии, номер 0 (реклама и аналитика). Завершение — окно «Обучение пройдено» без звёзд и времени, NEXT — первый уровень; провал — обычное окно. `GameFlow.IsTutorialLevel`.
- Шаг (`TutorialStep`): ключ текста `tutorial.*` (варианты `.touch`, `.hint`, `.hint.touch`; выпадающий список ключей из `Strings.tsv`), `Dialog`, `Goal` (Reach/Collect/UnlockDoor/OpenDoor/Kill/OpenMap/None), `Target` (id объекта, выпадающий список), `Cell`, `Highlight`. Проверяет `LevelValidator` (`TutorialStepInvalid`) и Build Localization (ключи шагов есть в таблице).
- `TutorialSystem` (Gameplay/Tutorial, стадия `SpawnZombies` после зомби): шаг завершается **состоянием** игры, проверка — по событиям (клетка, `PickupSystem.Removed`, двери, смерть зомби, `ReportMapOpened`); выполненный заранее шаг пропускается. Линии к цели нет (подсказка маршрута убрана) — только стрелка `TutorialPresenter`. Сценарий — от Maze (без шагов фрагмента и выхода); при `AllKilledRule` обучение завершается на последнем убитом зомби — переделывается в обучающий забег.
- `TutorialPresenter` (Presentation, `InitializeUI`) → `UIRoot.Tutorial` (`TutorialScreen` над HUD): окно шага через `DialogDelay` игрового времени → `GameFlow.OpenTip` (**`GameFlowState.Tip`** — пауза, HUD виден; «ПОНЯТНО», Enter/пробел/South — `IInputService.ConfirmRequested`, Esc; не раньше 0.35 с), строка-напоминание сверху, стрелка над целью (у края экрана — к цели), пульсирующее кольцо вокруг кнопки (`Highlight`: тач-элементы, карта, слоты на ПК). Аналитика — `tutorial_step`.
