Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

Монстры разбиты на справочники: [Zombies.md](Zombies.md) — зомби Maze · [Monsters.md](Monsters.md) — данные, вид рядовых, восприятие, сложность · [Abilities.md](Abilities.md) — способности, офицеры, Громила, двери, масса · [Elite.md](Elite.md) — элита, чемпионы, эффекты монстров · [Horde.md](Horde.md) — орда, песочница, стресс-тест.

## Монстры этапа 5 (рядовые — 5а)
- **Определение** — `MonsterDefinition` (`Core/Monsters`, `ContentDefinition`, меню Purge/Definitions/Monster): ранг `MonsterRank` (Mass/Officer/Elite/Boss), биом `MonsterBiome`, восприятие `MonsterPerception` (Wanderer/Caller/Hunter — `HordePerception`, 5б; Ходок и биомные — бродяги, Бегун — охотник), статы `MonsterStats` (HP, скорость, радиус, досягаемость, урон, интервал атаки, поворот, расталкивание, время трупа, **`EmergeTime`** — сколько вылезает из-под земли; восприятие 5б: `WanderSpeed` — шаг бродяги, клип ходьбы 1× при `MonsterStats.WalkClipSpeed` 0,4 кл/с; `SightRange` 7; `CallRadius` 12 — у зовущих), дроп `DropTable` (ранга; пусто — уровня), сопротивления `StatusResistance` (состояние × длительность, 0 = иммунитет), эффекты смерти — `[SerializeReference, ModuleList] List<EffectModule>` (те же, что у метательного).
  - **Вид не здесь**: каталог контента грузит все определения при старте — тяжёлое (меш, текстуры костей, экипировка) лежит в `HordeVisualDefinition` с `MonsterId` (`[ContentRef]`).
- **Создание** — **Purge → Dev → Build Monsters** (`MonstersBuilder`): по папкам `Art/Monster/<Биом>/<Ранг>`; рядовые (Mass) — запечённые, офицеры (5в, кроме `Ram_*`) — Animator, раздел «Способности и офицеры».
  - Определения — `Data/Monsters/<Биом>/<префаб>.asset` (id = имя префаба: `zombie_common` — Ходок, `zombie_2_common` — Бегун, `skeleton_castle`, `zombie_forest`, `ghoul_snow`), виды — `Data/Monsters/Visuals/<префаб>.asset`, запечённое — `Art/Horde/<префаб>/`.
  - Клипы `Monster_*` в `Art/Animations` (копии из Zombie_Animations и UAC: ожидание, 2 ходьбы, бег, 2 спринта, 3 атаки, 3 реакции, оглушение UAC Bare Fists, 4 смерти по сторонам UAC, появление = `Crawl_OutOfGround` + `CrawlIdle_To_Stand`; с 5д1 — только окна 2,4–5,0 с и 0,6–3,2 с с переходом 0,4 с на стыке: весь клип 13,3 с в 2 с дёргался ×7, теперь ~4,8 с ×2,4, 72 кадра — `ClipEntry.Windows`/`Blend`).
  - Ходьба паков — шарканье 0,2–0,6 кл/с, поэтому погоня всегда бег (`Run_02`, ~2,2 кл/с) или спринт (≥ 2,8 кл/с, ~3,4); ходьба запечена для бродяг 5б.
  - **Клипы запекаются на месте**: атаки Zombie_Animations — версии с перемещением (выпад бёдер ~1,4 м), реакции отходят назад, появление ползёт ~1,9 м — горизонтальный уход бёдер от первого кадра клипа вычитается (иначе монстр «прыгает» сквозь игрока и отскакивает на каждом повторе)
  - у смертей уход оставлен (`ClipEntry.KeepDrift` — тело падает). Запекание экономит размер: у `HordeClip.FrameRate` своя частота (атаки, смерти, оглушение, ожидание — 15 к/с, реакции — первые 0,8 с, появление — 60 кадров на весь клип) → ~590–610 кадров, ~0,7 МБ на вид (RGBAHalf 150 × кадры).
- **Экипировка рядовых** — список `HordeEquipment` (кость Humanoid → модель) в виде; модель вклеивается в меш с весом 1 на кость в бинд-позе, сдвиг/поворот/масштаб — компонент `EquipmentModel` (`Core/Visual`) на префабе модели, общий для всех монстров (билдер добавляет его с нулями).
  - Подсетка на материал+кость — у вида `ExtraMaterials`, рисуется вторым вызовом на пачку. Сейчас — меч `SM_Wep_Sword_09` у Скелета.
- **Орда с видами** — `StressTestDefinition.Monsters` (`HordeSpawn`: монстр + вес) → `HordeSystem.KindList` (`HordeKind`: определение + статы); пусто — встроенный монстр (`StressTestDefinition.Monster` + `Visual`, стресс-тест).
  - На слот — `Kinds` (индекс вида), `StatsOf/DefinitionOf/RadiusOf(agent)`, `MaxRadius` для запросов; расталкивание — по сумме радиусов. Новое состояние **`Emerging`**: замена (не первая волна) `EmergeTime` секунд вылезает из-под земли — по ней бьют (`IsAlive`), но она не ходит и не атакует.
  - Вид слота выбирается по весам (`DeterministicRandom`).
- **Сопротивления** — `StatusSystem.Apply` умножает длительность на `DurationFactor` монстра. **Дроп** — `DropSystem` берёт таблицу монстра (`HordeDrop` у рядовых), иначе пула.
  - **Эффекты смерти** — `MonsterDeathEffects` (Gameplay/Effects, после `DropSystem`): на `Killed` ставит в очередь, применяет на следующем тике (`EffectSystem.Apply`, `hostile`), чтобы цепочки взрывов не рекурсировали в уроне орды.
- **Вид** — `HordeRenderer`: вид на каждый вид монстра (`StressTestDefinition.VisualOf`, `MonsterVisuals` — Build Monsters кладёт виды монстров из списка), пачки по (вид × материал).
  - Клип по состоянию: смерть (сторона — по толчку убийства относительно взгляда: толчок назад = удар спереди → `Death_Front`; слабый толчок — любая), появление (клип сжат в `EmergeTime`), оглушение, реакция на удар (пока монстр в `Stagger`; новый удар перезапускает после 0,3 с), атака (сжата в интервал), бег (фаза копится со скоростью монстра / `LocomotionSpeed` вида, 0,5–2×).
  - Цвет брызг — `SplashColorOf(agent)`. Тень-пятно — по радиусу.
- **Восприятие (5б)** — `HordePerception` (Gameplay/Horde, создаёт и ведёт `HordeSystem`; получает `SoundEventBus` и `VisibilitySystem`): на слот `HordeAwareness` — Wander / Investigate / Alert / Chase. Охотник — сразу Chase.
  - **Бродяги** идут шагом (`HordePace.Walk`, `WanderSpeed`) с одной из `StressTestDefinition.WanderGroups` групп (слот % групп) к её случайной достижимой точке: на группу свой `FlowField`, новая точка раз в `WanderRetarget` с (сдвиг между группами), не больше одной пересборки за тик, двери — пересборка
  - у точки стоят (idle). Поля групп создаются, только если какой-то вид не охотник. На этапе 6 точку заменит маршрут волны.
  - **Слух**: все звуки шины (кроме чужого этажа) копятся и раз в `ProcessInterval` 0,2 с превращаются в `NoiseField` (Core/Navigation): громкость = радиус − путь (орт. 1, диаг. √2, без срезания углов), окно ±радиус (≤ 24), стену (`BlocksSight`) звук не проходит, кусты/ящики — проходит, закрытая дверь × `ClosedDoorTransmission` 0,5.
    - Звуки одного типа ближе 2 клеток склеиваются (очередь автомата — одно поле; последнее место, наибольший радиус), поле того же звука с того же места пересобирается, иначе вытесняется самое старое из `NoiseSlots` 8. Радиус × `DifficultyDefinition.Hearing`.
    - Услышавший бродяга → Investigate: бежит (`Speed`) по шагам поля к источнику (через закрытую дверь не проходит — упирается); у источника или поле вытеснено → снова Wander. Новый звук перебивает старый.
  - **Зрение**: круг, раз в 0,2 с — клетка монстра в обзоре игрока и игрок ближе `SightRange` × `Sight`. Заметил (зрение, попадание `Damage`, зов) → Alert: стоит лицом к игроку `AlertTime` 0,5 с (idle), потом Chase **навсегда** (игрок не теряется). Незнающие не атакуют.
  - **Зов**: зовущий, заметивший игрока сам, в конце рыка шлёт `SoundType.Call` (`CallRadius` × `Call`, по проходам как звук; × слух не множится): все, кто его слышит, → Alert → Chase; позванные не зовут дальше (без цепочки). Счётчики `Calls`, `FieldBuilds`.
  - Песочница: `AllHunters` (все охотники), `HordeSystem.SpawnGroup` (10 монстров вокруг точки, восприятие поверх данных вида, первый — зовущий) и `SpawnAt` (тесты). `HordeSystem.Paces` — как монстр шёл в этом тике: `HordeRenderer` играет бег по скорости, ходьбу (клипы Walk, темп `WanderSpeed / 0,4`) или ожидание (стоит, рычит).
- **Сложность** — `DifficultyDefinition` (`Core/Monsters`, `Data/Difficulty/Easy|Normal|Hard|Unreal`, меню Purge/Definitions/Difficulty): уровень `DifficultyLevel` + множители слуха, зрения, зова (черновые 0,8 / 1 / 1,2 / 1,4); статы по сложности — этап 6. Пока берётся из `StressTestDefinition.Difficulty` (песочница — Normal, пусто = все 1).
- Песочница: Ходок 3, Бегун 2, Скелет/Лесной зомби/Гуль по 1, `EmergeTime` 2 с.
