# Платформы: веб, аналитика, реклама, площадки, RuStore

Справочник по текущему коду (перенесён из CLAUDE.md 2026-10-17). Читать, когда задача касается этих систем; **обновлять при их изменении.** Общие правила — [CLAUDE.md](../../CLAUDE.md).

## Платформа: аналитика и реклама
- **Веб (этап 55):** `AppFocusController` — страница скрыта/без фокуса (`focusChanged` + `WebPage`/`Plugins/WebGL/PurgePage.jslib` visibilitychange) → тишина и пауза уровня (в редакторе выключен); звук гасит `SoundSuspension` по причинам (реклама, фон) — `AudioListener.pause` напрямую не трогать. Пауза ещё на **P** (fullscreen-браузер забирает Escape). `RotateDeviceScreen` — «Поверните устройство» на мобильном в портрете (поверх всего, пауза через `ScreenRouter`). WebGL-шаблон `Assets/WebGLTemplates/Mazebound` (без прокрутки/жестов, DPR ≤ 2 на мобильных); release-настройки WebGL ставит `PurgeBuilder` (Brotli + fallback, хеши имён, IL2CPP size, stripping Medium + `_Project/link.xml`, http разрешён — иначе сборка по LAN не грузит Addressables; текстуры — подцель **ASTC**: в мобильных браузерах нет DXT). Нет rewarded (Failed/Unavailable) — `AdsService.ShowRewardedResultAsync` (строка `ad.unavailable`; показывать её — забота нового места за rewarded). Проверка на телефоне — сборка по `http://<ip>:8080`, консоль браузера — CDP через `adb forward … chrome_devtools_remote`.
- `Application/Platform`. **Аналитика:** `AnalyticsService` (IApplicationService) раздаёт события всем `IAnalyticsSink` (платформа = свой синк; сейчас `LogAnalyticsSink` → `GameLog` канал `Analytics`); упавший синк игру не ломает. Имена событий/параметров — `AnalyticsEvents` (стабильные строки). `GameAnalytics` (проектный, `Initialize` из `ApplicationEntryPoint`) по `GameFlow.StateChanged`: `session_start`, `level_start` (номер, попытка за сессию, откуда), `level_complete` (время, звёзды, убийства, смертей до победы, рекорд, средний FPS), `level_fail` (клетка, кто ударил последним), `level_quit`. Внутриуровневое собирает `LevelAnalytics` (уровневый скоуп) в `LevelRunStats` (проектный) + `weapon_pickup`; `ad` — из `AdsService`.
- **Реклама:** `AdsService` (IApplicationService) поверх `IAdProvider` (SDK платформы; сейчас `SimulatedAdProvider` — всё «показано», rewarded всегда засчитан): `ShowRewardedAsync(placement)` → bool награды; `ShowBeforeLevelAsync(levelId)` — interstitial по `AdPolicy` (не до уровня 4, не dev-уровни, не чаще 90 с после любой рекламы, время реальное). На время рекламы `AudioListener.pause`. Ошибка SDK = нет награды. `GameFlow` показывает interstitial после выгрузки старого уровня, до загрузки нового (необязательный параметр конструктора).
- **Площадка (этап 56):** `IGamePlatform` (SDK сайта: `InitializeAsync`, `Language`, `CloudSave`, `LoadingFinished`, `GameplayStarted/Stopped`, `HappyMoment`), без сайта — `GenericPlatform`. `PlatformService` — первый `IApplicationService` (упавший SDK = нет площадки, игра идёт). `PlatformEvents` по `GameFlow.StateChanged`: первый `MainMenu` → загрузка закончена, только `Playing` = геймплей, `Completed` с 3 звёздами (не обучение) → радостный момент. Язык: сохранённый → язык площадки (`LanguageCatalog.Choose(saved, platform, system)`, «en-US» → «en») → системный. **Облачный сейв** (`ICloudSave` площадки) в `SaveService`: при старте облако важнее локального (локальная копия перезаписывается), пустое облако получает локальный сейв; `Save()` пишет локально сразу, в облако — через `CloudDelay` (2 с, склейка), при уходе в фон — сразу (`AppFocusController` → `FlushCloud`); облако, не ответившее при старте, в эту сессию не пишется. Полный сейв 30 уровней ≈ 4 КБ.
- **Сборка под площадку:** `PurgeBuilder.Build(target, development, WebPlatform)` (`Editor/Build/WebPlatform.cs`): symbol площадки (`PURGE_YANDEX`, `PURGE_CRAZYGAMES`, `PURGE_VK`, `PURGE_GAMEDISTRIBUTION`) — только в `extraScriptingDefines` сборки плеера (редактор без него), папка `Builds/WebGL-<площадка>[-dev]`, SDK-скрипт — в `<head>` шаблона через `{{{ PURGE_PLATFORM_HEAD }}}` (`WebPlatforms.Head`). Регистрация реализаций площадки — `#if` в `ProjectLifetimeScope`. Пункты меню площадки добавляет её этап.
- Подключение SDK: новый `IAnalyticsSink`/`IAdProvider` и регистрация по платформе в `ProjectLifetimeScope` (там помечено место).
- **Яндекс Игры:** мост `Plugins/WebGL/PurgeYandex.jslib` ↔ `YandexBridge` (`Application/Platform/Yandex.cs`: запрос с id → один ответ код+текст; id 0 — события сайта `game_api_pause/resume`; вне WebGL-плеера вызовы бросают → игра как Generic); `YandexPlatform` (язык `environment.i18n.lang`, `ICloudSave` = `player.getData/setData` ключ `save`, вход `auth.openAuthDialog`, `LoadingAPI.ready`, `GameplayAPI`; init с таймаутом 10 с), `YandexAdProvider` (fullscreen/rewarded → `AdResult`), `YandexMetrikaSink` (`ym reachGoal`, только если задан `WebPlatforms.YandexMetrikaCounter`). Регистрация — `#if PURGE_YANDEX`. Пауза сайта → `PlatformService.PauseRequested` → `AppFocusController` (тишина + пауза уровня). **Вход** — только по кнопке игрока (меню справа вверху, `AccountService` → `ScreenRouter`), после входа `SaveService.MergeCloudAsync`: сейв аккаунта сливается с текущим (`SaveData.MergeFrom`: см. «Фундамент данных» — максимум/объединение, настройки и забег — текущие). Sticky-баннер включается в консоли ЯИ (ПК — да, мобильные — после проверки). Локально — `sdk-dev-proxy` (PurgeMenu.md).
- **CrazyGames (этап 60):** `Plugins/WebGL/PurgeCrazy.jslib` ↔ `CrazyBridge` (`CrazyGames.cs`, общая часть мостов — `WebCalls`), `CrazyGamesPlatform` (locale из `systemInfo`, сейв — Data module ключ `save`, вход `showAuthPrompt` + auth listener → `PlatformService.SignedIn` → `AccountService` сливает сейв, `settings.muteAudio` → `SoundSuspendReason.Platform`, `loadingStop`/`gameplayStart/Stop`/`happytime`), `CrazyGamesAdProvider` (`adsDisabledBasicLaunch` → `AdResult.Disabled` = награда бесплатно; interstitial только между уровнями — `IAdProvider.InterstitialBetweenLevelsOnly`). Правила площадок — `PlatformTraits` (`StartsInGameplay`: новый игрок сразу в обучение — `ApplicationEntryPoint`; `TracksFocusItself`: пауза из-за фона не сообщается — `PlatformEvents`). **Для всех площадок:** PLAY — следующий непройденный уровень сразу, выбор уровня — кнопка LEVELS; звук глушится по реальному старту рекламы (`IAdProvider.ShowAsync(…, started, …)`), пока реклама запрошена — карту не закрыть (`GameFlow.CloseMap`); happytime — только при первых 3 звёздах уровня (`GameFlow.LastPreviousStars`).

- **Игры ВКонтакте (этап 61):** `Plugins/WebGL/PurgeVk.jslib` ↔ `VkBridge` (`Application/Platform/Vk.cs`); VK Bridge 3.0.2 — файл `WebPlatforms/Vk/vk-bridge.min.js` (вне Assets), `PurgeBuilder` копирует его к странице, `VKWebAppInit` — в `<head>` до загрузки игры; готовность — реальный вызов `VKWebAppGetLaunchParams` (вне ВК не отвечает → Generic по таймауту). `VkPlatform`: язык `vk_language` (`kz`→`kk`), входа нет (все залогинены), `PauseRequested` по `VKWebAppViewHide/Restore`, баннер `VKWebAppShowBannerAd` снизу, `resize` (окно игры ужимается; на телефонах компактный, `VkPlatform.MobileBanner`, включён для оценки); отступы системных панелей — `insets` VK (приложение ВК на Android панель навигации не сообщает → на телефоне по бокам минимум 48 CSS px, `PurgeVk.jslib`; этого не хватило — на телефоне в ВК кнопки справа сверху (пауза, карта, крестик и лупа карты) ещё сдвинуты влево на кнопку: `PlatformTraits.TopRightButtonsShift` → `HudScreen/MapScreen.ShiftTopRightButtons`) → `window.purgeSetSiteInsets` (`PurgePage.jslib`, вместе с CSS `env(safe-area-inset-*)`) → `WebPage.Insets` → `SafeAreaFitter`/`TouchControls` (safe area — только через `WebPage.SafeArea`, не голый `Screen.safeArea`), `PlatformTraits.SupportEmail` → строка «Поддержка» в настройках (Other). Сейв — VK Storage через **`SlottedCloudSave`** (`IKeyValueStorage`): значение ≤ 4096 символов, ≤ 1000 вызовов/ч → JSON частями по 1000 в слоты A/B, указатель `save_slot` («B:3») пишется последним (оборванная запись не портит сейв), неизменённый сейв не пишется; читать до первой записи. `VkAdProvider`: `VKWebAppShowNativeAds` (предзагрузка `CheckNativeAds` в мосте раз в минуту), события старта нет → тишина при запросе. Хостинг VK: адрес меняется при каждой выкладке (поэтому облако), аудио/видеофайлы запрещены, выкладка `vk-miniapps-deploy` по `Builds/vk-hosting-config.json` (`WebPlatforms.VkAppId`). Одноклассники — позже (та же сборка).

- **GameDistribution (этап 64):** `Plugins/WebGL/PurgeGd.jslib` ↔ `GdBridge` (`Application/Platform/GameDistribution.cs`); `GD_OPTIONS` + загрузчик SDK — в `<head>` (`WebPlatforms.Head`, Game ID — `WebPlatforms.GameDistributionGameId`), `onEvent` хранит SDK_READY в `window.purgeGd` (может прийти до старта игры). `GameDistributionPlatform` — без языка, облака, входа и событий; пауза SDK вне нашей рекламы → `PauseRequested`. `GameDistributionAdProvider`: `IAdProvider.ManagesInterstitialFrequency` = true → `AdPolicy` не применяется, interstitial на каждом перерыве — старт уровня (и первый PLAY) и `AdsService.ShowOnMenuReturnAsync` (выход в меню с окна результата, `GameFlow.OpenMainMenu`); rewarded — `preloadAd` заранее, награда только по `SDK_REWARDED_WATCH_COMPLETE`, reject = `Unavailable`. Запрещено правилами GD: внешние ссылки, контакты, чужая реклама и аналитика, покупки (`PlatformTraits` по умолчанию, синка нет). Активация игры — досмотреть тестовый pre-roll в iframe панели GD.
- **RuStore (этап 62, Android):** `PURGE_RUSTORE` — define Android-сборки (`AndroidStore`/`AndroidStores` в `Editor/Build/AndroidStore.cs`, меню **Android RuStore APK**). SDK (сервисы Яндекса недоступны → VK, решение 2026-10-13): **Рекламная сеть VK** (myTarget) и **MyTracker** — исходники Unity-плагинов в `Assets/Plugins/MyTarget`, `Assets/Plugins/MyTracker` (свои asmdef `MyTarget`/`MyTracker`, `UNITY_ANDROID || UNITY_EDITOR`; Android-библиотеки закреплены в `Editor/*Dependencies.xml` на версиях, под которые написан плагин: mytarget-sdk 5.27.4 — его `AndroidJavaProxy`-слушатели должны совпадать с интерфейсами SDK; что взято из пакетов — README в папках); EDM — пакет Unity `com.unity.external-dependency-manager` 2.1.1 (те же DLL Google; OpenUPM-пакет `com.google.external-dependency-manager` устарел — его подменяет пустая встроенная заглушка `Packages/com.google.external-dependency-manager`, не удалять; настройки без диалогов — `ProjectSettings/GvhProjectSettings.xml`, `ExternalDependencyManager*`; `PurgeBuilder` создаёт Gradle-шаблоны в `Assets/Plugins/Android` и вызывает `ResolveSync`; в `gradleTemplate.properties` — `android.useFullClasspathForDexingTransform=true` для myTarget). Адаптеры — отдельная сборка **`Purge.Application.Android`** (`Scripts/Application/Platform/Android`, define constraint `UNITY_ANDROID || UNITY_EDITOR`): `RuStorePlatform` (system language, local save, `PlatformTraits.SupportEmail` + `PrivacyPolicyUrl` → строки в настройках Other), `VkAdsProvider` (по одному rewarded/interstitial заранее — объект рекламы одноразовый, повтор загрузки 10→120 с, rewarded ждёт загрузку 4 с, результат — через 3 кадра после закрытия: плагин отдаёт по одному колбэку за кадр), `MyTrackerSink` (параметры → строки ≤ 64 символов, без ключа выключен). Ключи — **`RuStoreKeys`** (пусто/0 = демо-слоты VK 45101/10138 / MyTracker выкл.). SDK-сборки из не-Android плееров убирает `AndroidSdkAssemblyFilter`. Проверка компиляции под Android без смены платформы — `PlayerBuildInterface.CompilePlayerScripts` (target Android, define `PURGE_RUSTORE`). Пакет `ru.bgames.mazebound`, компания BGames, versionCode из Version `x.y.z`, ARM64+ARMv7, APK, release-подпись — `UserSettings/PurgeAndroidSigning.json` (не в git; путь/пароли сбрасываются после сборки). Контакты — `Contacts` (почта, политика — `Docs/PrivacyPolicy/privacy.html` на GitHub Pages). Заставка Unity выключена (все платформы).
