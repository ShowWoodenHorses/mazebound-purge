# Машины-тараны (этап 9)

Справочник по текущему коду. Читать, когда задача касается машин; **обновлять при их изменении.** Решения — карточка этапа 9 в [TZ.md](../TZ.md). Сделано: 9а (езда), 9б (таран и поломка); машины на уровне (генератор, кисть, сейв, аналитика) — 9в.

## Данные (Core/Vehicles, `Data/Vehicles`, Build Vehicles)
- `VehicleDefinition` (`ContentDefinition`) — список модулей `VehicleModule`: **Engine** (`MaxSpeed`, `Acceleration`, `Braking`, `Rolling` — накат без педалей, `ReverseSpeed`, `Power` — для 9б), **Steering** (`TurnRadius`), **Hull** (`Health`, `Length`/`Width` — прямоугольник корпуса, `WallSafeSpeed`, `WallDamage`), **Ram** (9б: `Mass`, `MinSpeed` 2, `KillShare` 0,5, `Wear` 4 / `OfficerWear` 12 — износ корпуса за сбитого, `HeavyShare` 0,15, `Bounce` 0,35, `BounceDamage`, `Stun` + `StunTime` 1), **Wreck** (9б: `BreakTime` 1,5, `PushRadius` 3, `PushSpeed`, `Invulnerability` 1, `Effects` — модули эффектов, взрыв), **Look** (`Prefab`, `CameraZoom`, звуки двигателя `Idle/Drive/Start/Rev` — `[VehicleSound]`, выпадающий список папок `Sounds/Vehicle`; `Smoke` — дым поломки).
  - Engine/Steering/Hull обязательны (`Validate`); без модуля — значения по умолчанию.
- На уровне — `VehicleData` (`LevelData.Vehicles`, id `vehicle_N`): клетка центра корпуса, `Definition` (прямая ссылка), `Heading` — градусы по часовой от севера. `LevelEditing.AddVehicle`. В `AllEntities` есть; общая фабрика видов (`LevelVisualSystem`) их пропускает.
- **Build Vehicles** (`VehiclesBuilder`): префаб `Art/Vehicles/<имя>` → `Data/Vehicles/<имя>.asset`; новый — черновики по размеру модели (длиннее 4,2 м — тяжёлая: взрыв r 4 / 260 против r 3 / 150), звуки по последнему слову имени; у существующего дополняет, чего нет: Wreck, `Ram.Stun` (`Status_Stun`), `Look.Smoke` (`FX_Vehicle_Smoke`). Модели: `Vehicle_Light` (`SM_Veh_Car_Medium_01`), `Vehicle_Heavy` (`SM_Veh_Truck_01` + `_Tanker`) из PolygonMilitary, без коллайдеров, центр корпуса в начале координат, **корень префаба ×0,75** (как монстры; 2026-10-28) — корпус лёгкой 3,5×1,4, тяжёлой 5,2×2,0.

## Геймплей (Gameplay/Vehicles)
- `VehicleBody` — геометрия без физики: курс в радианах по часовой от севера, перед `(sin h, cos h)`; пересечение прямоугольника с клеткой (SAT), клетки под корпусом (`Cells`, с отступом), расстояние до точки, отрезок (`Segment`, для пуль).
- `VehicleSystem` (шаг `InitializeSystems`, тик **сразу после `PlayerSystem`**): `Vehicle` — `Position`, `Heading`, `Speed` (со знаком), `Steer`, `Throttle`, `Health`, `State` (Parked/Driven), `InContact`, `IsScraping`.
  - **Стоящая** — `CellBlockers` на клетки корпуса (с отступом 0,2: угол, задевший клетку, её не закрывает), `IShotBlocker` в `SpatialQueryService` (пули, снаряды, `IsClear` по `BlocksBullets`; обзор проходит), монстров из закрытых клеток выталкивает `HordeSystem.PushOutOfBlocked`.
  - `FindEnterable` — стоящая в пределах `EnterReach` (1 клетка) от игрока; `Enter` — снимает блоки, `PlayerSystem.EnterVehicle`, `WeaponSystem.InputLocked`; `TryExit` — паркует, ищет место игроку: левый бок (3 точки), правый, зад, перед, с шагом отступа, пока ноги не выйдут из закрытых клеток; нет места — остаётся внутри.
  - **Езда**: газ `PlayerAction.Gas` (W, ↑, RT, кнопка Газ), тормоз/назад `Brake` (S, ↓, LT, кнопка Тормоз), руль — `Move.x` (мёртвая зона 0,15). Поворот только в движении: радиус `TurnRadius` + 0,25 × |скорость|.
  - Движение подшагами ≤ 0,2: стена при угле курса к ней < 45° — скольжение вдоль (`IsScraping`), иначе остановка вплотную (деление шага пополам); урон корпусу при новом касании = (нормальная скорость − `WallSafeSpeed`) × `WallDamage`, событие `WallHit`. Поворот, упёршийся в стену, не делается.
- **Таран (9б)** — `Ram` после каждого подшага движения: живые монстры, которых задел корпус (корзины орды). Медленнее `MinSpeed` — не таранит (орда выталкивается из корпуса сама). Рядовые и офицеры — урон масса × скорость через `CombatTargets.Damage` (рядовой от `KillShare` макс. скорости — насмерть), вбок `HordeSystem.Push` (труп — вперёд по ходу), торможение по импульсу `speed × MP / (MP + масса монстра)` (M — масса машины, P — `Engine.Power`), износ `Wear`/`OfficerWear`; повтор по тому же монстру — не раньше `RamCooldown` 0,5 с. Элита и боссы **впереди по ходу**: машина назад на шаг, на скорости — отскок (`-speed × Bounce`), им `HeavyShare` урона тарана и `Stun` (`StatusSystem`, у боссов ×0,25), машине `BounceDamage`; медленно — просто стоп. События `Rammed` (раз в тик: сбито, убито), `Bounced`; счётчики `RamHits`, `RamKills`.
- **Удары по машине** — `HordeSystem.Shell` (`IPlayerShell`, ставится при посадке): дистанция атаки монстров — до корпуса (+ радиус игрока), в конце тика орды монстры выталкиваются из корпуса целиком (`ResolveShellContacts`, неподвижные — нет). Урон игроку в машине (удары, снаряды, зоны) — `PlayerHealth.Shield` (`IPlayerShield`) → `VehicleSystem.Hurt`; стены — тоже `Hurt`.
- **Поломка (9б)** — HP 0: `Broken`, `BrokeDown`, газ не работает (тормоз и накат — да), через `BreakTime` (`BreakLeft`, в тике) `Explode`: игрок внутри — место выхода как у `TryExit` (нет — центр машины), `Ejected`, отталкивание монстров `PushRadius`, щит `Invulnerability` с; затем `EffectSystem.Apply(Wreck.Effects, hostile: false)` — игрока не ранит; `State = Destroyed`, `Exploded`. Выйти во время дыма можно — взорвётся без игрока. Сломанная/взорванная — не сесть.
- `PlayerSystem` в машине: `InVehicle`, `Ride` (позиция и взгляд машины; **клетка игрока обновляется не чаще `RideCellInterval` 0,25 с** — поле пути орды, видимость, подбор), `ExitVehicle`; толчки/`Knock`/`Displace` не действуют. `PlayerCombat`, `PlayerThrowing` в машине не атакуют и не бросают.
- `PlayerInteraction`: в машине Use — только выйти (`VehicleExited` / `VehicleExitBlocked`); пешком порядок: оружие → метательное → сундук → **машина** → дверь (`InteractionTarget.Vehicle`).

## Вид, звук, HUD
- `VehicleViewPresenter` (`BuildVisuals`, `IViewWarmup`): модель Look на машину, `EntityView` (`VisualKind.Vehicle`, видимость по клетке центра), каждый late tick — позиция, курс, колёса (дети `*Wheel*`: катятся по пройденному, `*Wheel_f*` поворачиваются до 30°, вращение в системе машины). Камера: `TopDownCamera.ExtraHalfExtent` = `CameraZoom` × доля скорости, сглажено 0,6 с. Сломанная — `Look.Smoke` над капотом (`PackEffectsPlayer.Follow/Move`; эффекты машин уровня — дым и `Wreck.Effects` — грузит `PackEffectsPlayer`); взорванная — скрыта и убрана из `EntityViewRegistry`. Дым — `FX_Vehicle_Smoke` (Synty `FX_Smoke_Black_01` ×0,7, Flat; Build Pack Effects).
- `VehicleHudPresenter`: полоска HP (`HudScreen.VehicleBar`, `HudWorldBar` цвета здоровья) над едущей машиной.
- Всплески смертей: дроп — общий `MaxLying`, эффекты смерти — `MonsterDeathEffects.MaxPerTick` 6 за тик (остальные ждут), звук удара — один на тик, `kill_pop` — `MinInterval`/`MaxVoices` кью.
- `PlayerViewPresenter`: в машине модель игрока выключена, камера следует.
- `VehicleAudioPresenter`: дверь и запуск при посадке, дверь при выходе; холостой ↔ ход (петли, перекрёстно до 25 % скорости, тон хода 0,75–1,35 — `AudioService.SetVoice(…, pitch)`), рёв при газе с места, `wall_hit` по силе удара, `scrape_loop` при скольжении; 9б: `monster_hit` раз в тик тарана (громче при 1→6 сбитых), `bounce`, `stall` при поломке в машине, петля `smoke_loop` пока сломанная едет (холостой гаснет), взрыв — звук эффекта взрыва. Общие звуки — папки `Sounds/Vehicle/<имя>`.
- Тач: в машине `TouchAttackCluster.SetDriving` прячет контейнер `Combat` (атака, стик прицела, слоты, бросок) и показывает `Drive` — Газ (вся четверть, `<Gamepad>/rightTrigger`) и Тормоз (сектор на дуге, `leftTrigger`); Use со значком машины (`UseTarget.Vehicle`). Нет места выйти — `hud.vehicle.blocked`.
- Стенд: `Level_Sandbox` — все машины `Data/Vehicles` к юго-востоку от старта (Build Stress Test Levels). Тесты — `VehicleTests`, `VehicleRamTests` (9б).
