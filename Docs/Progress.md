## 4. Закреплённое

- **Enter Play Mode Options:** перезагрузка домена при входе в Play включена (`m_EnterPlayModeOptions: 0`, решение пользователя, перенесено из Maze). MCP на время PlayMode-прогонов временно её выключает; после каждого прогона проверить `ProjectSettings/EditorSettings.asset` и вернуть 0 через API.
- Классы генератора лабиринта (`MazeGenerator`, `MazeSeed`, `MazeAlgorithm` и их тесты) намеренно не переименованы — удаляются на этапе чистки.
- Пометка «Maze patch» в плагине myTarget — история правки, не переименовывать.
