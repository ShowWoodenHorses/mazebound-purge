## 3. Решения проекта

Игровые решения — в [TZ.md](TZ.md) (раздел «Решено»). Здесь — решения о самом проекте.

### Основа

- Копия Maze, а не новый проект с нуля; новый репозиторий с одним начальным коммитом
- *Почему / когда:* История Maze остаётся в Maze (2026-10-13)

### Имена

- Название **Mazebound: Purge**, кодовое имя **`Purge`** (не зависит от названия)
- *Почему / когда:* Решение пользователя 2026-10-13

### Пакет и версия

- `ru.bgames.mazebound.purge`, версия 0.1.0 (versionCode 100)

### Общий код с Maze

- Не выносится в пакет: исправления площадок/сейва/UI переносятся руками
- *Почему / когда:* Решение пользователя 2026-10-13

### Документы Maze

- Архив `Docs/Maze/` (ТЗ, прогресс, CLAUDE.md) — без изменений; справочники меню, Level Designer, префабов переименованы и правятся по ходу

### ID площадок и рекламы

- Обнулены: ВК App ID, GameDistribution Game ID, слоты VK Ads и ключ MyTracker (RuStore — демо-слоты)
- *Почему / когда:* У новой игры свои, заводятся на этапах площадок

### Релиз

- 3 локации + выживание, остальное — обновлениями; первые площадки CrazyGames и RuStore
- *Почему / когда:* Решение пользователя 2026-10-13

### Победа до волн

- Временное правило `AllKilledRule`: последний убитый зомби завершает уровень (звёзды Maze: завершение + все зомби + бывшая звезда фрагментов — всегда). С 6а уровни с волнами завершает `WavesClearedRule` (последняя волна); `AllKilledRule` остаётся для зомби Maze (обучение) до этапа 11

### Уровни Maze

- Level_01–30 удалены; остались dev-уровни (Items, weapon, light) и обучение Maze; `Level_Dev` временно в основном каталоге (PLAY)

### ❓ визуал на толпе

### Видимость

### Этажи на этапе 3

- Данные + ядро: этаж в `GridPosition`, все клеточные системы в пределах этажа; лестницы, переход, показ этажей, карта по этажам — этап 8
- *Почему / когда:* Решение пользователя 2026-10-14

### Стабильные id

- Читаемые, из имени файла при создании, дальше не меняются (`forest_zombie_walker`); дубли зомби Maze (`hunter` ×3) переименованы
- *Почему / когда:* Решение пользователя 2026-10-14

### Сейв v1

- Новый формат с нуля, без миграций Maze (из старого сейва берутся только настройки); один документ
- *Почему / когда:* Решение пользователя 2026-10-14

### Модули

- `[SerializeReference]`-списки в ассете контента + меню Add module (а не модули отдельными ассетами)
- *Почему / когда:* Этап 3, 2026-10-14

### Ощущение стрельбы

- Приоритет проекта: каналы выстрел/попадание/убийство, профиль ощущения на оружие в данных, брызги цвета монстра, стрельба на ходу; на этапе 4 — имеющиеся звуки
- *Почему / когда:* Решение пользователя 2026-10-14 по отзывам игроков Maze

### Звук оружия: различимость

- У оружия своя звуковая группа (`Sounds/Weapon/<группа>/`), группы можно делить. Различие — свой сэмпл или **тон/громкость на оружие** (поле в звуковом модуле оружия — этап 4в; сейчас тон задаётся на группу): тот же выстрел ниже на 10–15 % звучит тяжелее (так разводятся, например, Драгунов и Lynx).
  - На оружие 2–4 варианта выстрела + случайный тон ±3–5 %
- *Почему / когда:* Обсуждение с пользователем 2026-10-16

### Звук оружия: автоогонь, калибр, перезарядка

- Автоматический огонь — повтор одиночных выстрелов по скорострельности из данных (петли пака с ней не совпадут); петли — только для непрерывного: миниган, огнемёт, лучи. Громкость на слух следует шуму калибра (9 мм < 5,45 < 7,62), глушитель — своя группа.
  - Перезарядка — по частям (магазин вынут / вставлен / затвор, барабан, патрон в трубку, баллон, батарея) под события клипа, части общие между классами. Хвост выстрела (эхо, 4–7 с) — один раз на конец очереди/одиночный, не на каждый выстрел.
  - Сведение: скорострельное — громкость ≤ 0.5 и 4–8 голосов на группу, ручное (снайперки, дробовики) — 0.7–0.9 (readme PostApocalypseGuns)
- *Почему / когда:* Обсуждение с пользователем 2026-10-16

### Звук оружия: классы

- Пистолеты (Glock базовый — звучит чаще всего, не должен утомлять; глушитель 9 мм; Desert Eagle; револьвер; Magnum), автоматы по калибрам (5,45 / 7,62 / 9 мм, 9 мм с глушителем, пулемёт, миниган с раскруткой), снайперки (AWM, охотничья, Драгунов, Lynx, с глушителем; продольный затвор), дробовики (помповый, авто, тяжёлый авто), заряды (арбалет, гранатомёт, РПГ + полёт ракеты, миномёт: закидывание, выстрел, свист падения), баллоны, энергия, ближнее, метательное (+ светошумовая, мина, турель)
  - общее для огнестрела — щелчок пустого, «мало патронов», достать/убрать, затвор, гильзы (латунь/дробь). **Ближнее — по весу взмаха** (лёгкий / средний / тяжёлый) **и типу удара** (клинок / тупой / тяжёлый), не по каждому оружию; **взрывы общие** (гранаты, РПГ, миномёт, бочки).
  - Калибры — 5,45 / 7,62 / 9 мм (не 5,56)
- *Почему / когда:* Решение пользователя 2026-10-16; раскладка — [SoundShortlist/README.md](SoundShortlist/README.md)

### Звуки: что не берём

- Безоружные удары (пустой слот = пистолет), звери и насекомые (животных нет), кровавое чавканье (стиль без крови), подбор бустеров (покупаются в меню), дыхание дракона, фитиль
- *Почему / когда:* Чистка шортлиста по ТЗ 2026-10-16

### Звуки: размер загрузки

- Звуки оружия сейчас в `AudioCatalog` (грузится при старте): ~40 стволов × 3–4 коротких MP3 ≈ 2–3 МБ к лимиту 20 МБ; при росте — грузить звуки оружия вместе с уровнем/оружием
- *Почему / когда:* Обсуждение 2026-10-16

### Цели боевой песочницы

- Оружие этапа 4 бьёт по орде (`HordeSystem`, плоские массивы), а не по `ZombieSystem` Maze: на орде строится этап 5, отбрасывание/вмятина всё равно в массивах
- *Почему / когда:* Решение пользователя 2026-10-15

### Деление этапа 4

- 4а оружие и стрельба → 4б метательное, зоны, дроп → 4в ощущение стрельбы и HUD
- *Почему / когда:* Решение пользователя 2026-10-15

### Анимации

- Клипы Maze заменяются: игрок — на этапе 4а из Ultimate Animation Collection (наборы по классам оружия, ходьба/бег с прицелом в 8 направлениях), зомби — на этапе 5 из Zombie_Animations (+ смерти ×4 из UAC, крик — рёв UAC Creature). Остаётся только `Player_use` (Use) из Maze.
  - Порядок: переписать списки клипов в билдерах (`PlayerAnimationsBuilder`, `WeaponsBuilder` — поза хвата `Grip_L`, `Build Zombie Animations`, `Build Horde Visuals`), перемерить `Aim Barrel`, проверить рендером и в игре — потом удалить старые клипы.
  - Клипы переносятся из `Import` в проект (без персонажей паков и демо-скриптов)
- *Почему / когда:* Решение пользователя 2026-10-15; разбор паков — [AssetsToFind.md](AssetsToFind.md) §4

### Модули оружия (4а)

- «Пуля» и «веер дроби» — один модуль `BulletAttack` (`Pellets` > 1 — веер); у атаки свой интервал и «автомат»; стрельба — ровно один модуль атаки
- *Почему / когда:* Этап 4а, 2026-10-17 (одна механика полёта — один код)

### Выброс оружия (4а)

- Магазин при выбросе и замене **не сбрасывается** (иначе «выбросил-подобрал» = бесплатная перезарядка); лежащее на уровне с начала — с полным магазином
- *Почему / когда:* Решение пользователя 2026-10-17

### Прицел на ПК (4а)

- Огонь — в точку под мышью (без автонаведения); геймпад — правый стик; телефон — направление движения с автонаведением. Касания не целятся (`Look` = только мышь)
- *Почему / когда:* Этап 4а, 2026-10-17

### Поворот при стрельбе (4а)

- Боевая стойка: корпус держит прицел 1 с после выстрела (без разворота туда-обратно между выстрелами при отступлении), поворот в прицеле плавнее; **ПК — корпус всегда к курсору** (twin-stick), ноги — по движению; телефон — автонаведение со стика движения: конус по ходу, затем ближайшая цель вокруг.
  - Бег спиной/боком без скольжения — анимации стрейфа UAC (шаг 4а)
- *Почему / когда:* Решение пользователя 2026-10-17 (отзыв: «на каждый выстрел перс разворачивается»)

### Забег (6)

- **Проверка** — отдельный dev-уровень `Level_Run`: площадка ~60×60 с препятствиями, 4–6 точек появления, сценарий ~5 волн / ~5 мин, запуск из главного меню Maze («Играть»). Песочница остаётся для бенча.
- **Карточки** — первый набор ~12 модулей-статов (урон, скорострельность, перезарядка, магазин, бег, макс. HP, лечение за убийство, радиус подбора, +метательное, сила взрывов, урон по горящим, крит); у карточки редкость и стопка уровней. Карточки банка идей и эволюции — этап 12. Переброс — заглушка rewarded (`IAdsService`), раз на каждое появление карточек.
- **Воскрешение** — полное HP, 2 с неуязвимости, волна отталкивания с оглушением вокруг игрока; rewarded — заглушка рекламы, навык персонажа — флаг в данных (сам навык — этап 10); до двух раз за забег.
- **Итог** вместо звёзд Maze: победа/смерть, волны, убийства, время, деньги забега, ×2 за rewarded, очки; деньги в сейв сразу; `Stars`/`BestTime` из `LevelRecord` убрать.
- **Очки** — сумма очков убитых (по рангу) × множитель сложности + бонус за волну; нужны только для лидерборда выживания, на уровнях — только в итоге.
- **Старт забега до меню этапа 10** — базовый пистолет + одно оружие из dev-настройки уровня, без бустеров; «Продолжить» — кнопка в текущем главном меню при наличии `RunSave`.
- **Деньги и опыт за убийство** — черновые числа в `MonsterDefinition` по рангу; «монетка к HUD» — в 6д.
- **Орда уровня — `HordeDefinition`** (`LevelData.Horde`): виды и их вид, чемпионы, ёмкость, сложность, дроп — для любого уровня; `StressTestDefinition` остаётся только dev (стресс-оружие, автопилот, бенч, оверлеи, песочница); dev-уровень ссылается на оба ассета. Выделено в 6а.
- **6б**: на уровне с волнами дроп **без таймера** — лежит до старта следующей волны, потом исчезает весь (лимит `MaxLying` остаётся; в песочнице — по-старому). Деньги за убийство по рангу **1 / 5 / 20 / 100** (× `Difficulty.Money`). Ставка пропуска — **поле волны**, по умолчанию номер волны (W2 — 2/с), × `Difficulty.Money`; перед первой волной пропуска нет.
  - HUD: волна/враги/деньги под таймером, отсчёт и кнопка в паузе, надписи «Волна N» / «Волна пройдена» (звук `win`), полный запас патронов в паузе.
