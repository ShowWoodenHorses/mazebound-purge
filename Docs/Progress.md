На оружие 2–4 варианта выстрела + случайный тон ±3–5 % | Обсуждение с пользователем 2026-10-16 |
| Звук оружия: автоогонь, калибр, перезарядка | Автоматический огонь — повтор одиночных выстрелов по скорострельности из данных (петли пака с ней не совпадут); петли — только для непрерывного: миниган, огнемёт, лучи. Громкость на слух следует шуму калибра (9 мм < 5,45 < 7,62), глушитель — своя группа. Перезарядка — по частям (магазин вынут / вставлен / затвор, барабан, патрон в трубку, баллон, батарея) под события клипа, части общие между классами.
