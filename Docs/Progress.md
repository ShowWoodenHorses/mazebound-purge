## 4. Закреплённое

- **Enter Play Mode Options:** перезагрузка домена при входе в Play включена (`m_EnterPlayModeOptions: 0`, решение пользователя, перенесено из Maze). MCP на время PlayMode-прогонов временно её выключает; после каждого прогона проверить `ProjectSettings/EditorSettings.asset` и вернуть 0 через API.
- Пометка «Maze patch» в плагине myTarget — история правки, не переименовывать.

## 5. Открытые пункты

- Обучение — сценарий Maze без шагов фрагмента и выхода; при `AllKilledRule` завершается на последнем убитом зомби (раньше шагов аптечки и карты). Переделывается в обучающий забег.
- Окно результата: подписи у звёзд «выход» и «карта» пустые (звёзды Maze) — до этапа 6.
- Звуки `Player/win`, `Other/map`, `UI/window_exit_level` больше ни к чему не привязаны (Build Audio покажет их неиспользуемыми); `win` — кандидат на конец волны.
- Заголовок «MAZEBOUND» в главном меню (`RuntimeScenesBuilder`, сцена Bootstrap) — меню переделывается на этапе 10.
- Политика конфиденциальности: `PlatformTraits.PrivacyPolicyUrl` указывает на страницу Maze — нужна своя (к выходу на площадки).
- Псевдоним ключа подписи Android — `mazebound` (keystore пользователя можно использовать и здесь).
- ❓ из [Inheritance.md](Inheritance.md): зоны зрения, следы, пар изо рта на толпе — решаются стресс-тестом.
- Сервер для платежей ВК — сервер пользователя (1 ГБ), отдельное обсуждение.

## 6. История

### 2026-10-14 — Этап 1 (часть 2): проверка в Unity, удаление систем лабиринта
- Проект открыт в Unity: компиляция чистая, EditMode 428/428, PlayMode 13/13 (до чистки). Ошибки шейдера `Synty/CharacterShader` в консоли импорта — URP-шейдер пака (один материал Wasteland), как в Maze.
- Удалено: генератор лабиринта (`MazeGenerator`, настройки Seed/Algorithm/Loop/Exits), выход (`ExitData`, `ExitSystem`, `GameFlowState.ExitConfirmation`, окно «Finish level?», Build Exits, наборы и префабы выходов), фрагменты карты (`MapFragmentData`, `MapSystem`, инструменты Fragment/Region, наборы, значки, счётчик HUD), подсказка маршрута (`RouteHintSystem`, `RouteLineView/Mesh`, `ThemeRoute`, шейдер `Purge/RouteLine`, Build Route Line, лупа на карте), патрули (`PatrolData`, состояние `ZombieState.Patrol`, инструмент Patrol), слои карты за рекламу (`SaveData.MapUnlocks`, `MapUnlock`, кнопки разблокировки, события `hint_used`/`map_layer_unlocked`), `TempLevelBuilder`, уровни Level_01–30, строки таблицы переводов этих систем.
- Новое: `OpenFieldGenerator` (Generate New — площадка со столбами по желанию) + тесты, `AllKilledRule` (победа — убиты все зомби), карта рисует весь уровень, обучение без линии маршрута (стрелка осталась).
- Данные: `Level_Dev` в основном каталоге; у оставшихся уровней убран визуал удалённых объектов, темы и наборы значков пересохранены без старых полей; Bootstrap/Game пересобраны, локализация пересобрана.
- Тесты после чистки: EditMode 402/402, PlayMode 13/13.
- `AddressableAssetsData/link.xml` — в `.gitignore` (артефакт сборки Addressables).
- WebGL release (Generic) собирается: 0 ошибок, 22,5 МБ всего (`Build` 8,7 МБ + бандлы 15 МБ), 8 мин. Начальная загрузка до `gameplayStart` не замерялась.
