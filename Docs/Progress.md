- *Почему / когда:* Решение пользователя 2026-10-14 по отзывам игроков Maze

### Звук оружия: различимость

- У оружия своя звуковая группа (`Sounds/Weapon/<группа>/`), группы можно делить. Различие — свой сэмпл или **тон/громкость на оружие** (поле в звуковом модуле оружия — этап 4в; сейчас тон задаётся на группу): тот же выстрел ниже на 10–15 % звучит тяжелее (так разводятся, например, Драгунов и Lynx).
  - На оружие 2–4 варианта выстрела + случайный тон ±3–5 %
- *Почему / когда:* Обсуждение с пользователем 2026-10-16

### Звук оружия: автоогонь, калибр, перезарядка

- Автоматический огонь — повтор одиночных выстрелов по скорострельности из данных (петли пака с ней не совпадут); петли — только для непрерывного: миниган, огнемёт, лучи. Громкость на слух следует шуму калибра (9 мм < 5,45 < 7,62), глушитель — своя группа.
  - Перезарядка — по частям (магазин вынут / вставлен / затвор, барабан, патрон в трубку, баллон, батарея) под события клипа, части общие между классами. Хвост выстрела (эхо, 4–7 с) — один раз на конец очереди/одиночный, не на каждый выстрел.
  - Сведение: скорострельное — громкость ≤ 0.5 и 4–8 голосов на группу, ручное (снайперки, дробовики) — 0.7–0.9 (readme PostApocalypseGuns)
- *Почему / когда:* Обсуждение с пользователем 2026-10-16

### Звук оружия: классы

- Пистолеты (Glock базовый — звучит чаще всего, не должен утомлять; глушитель 9 мм; Desert Eagle; револьвер; Magnum), автоматы по калибрам (5,45 / 7,62 / 9 мм, 9 мм с глушителем, пулемёт, миниган с раскруткой), снайперки (AWM, охотничья, Драгунов, Lynx, с глушителем; продольный затвор), дробовики (помповый, авто, тяжёлый авто), заряды (арбалет, гранатомёт, РПГ + полёт ракеты, миномёт: закидывание, выстрел, свист падения), баллоны, энергия, ближнее, метательное (+ светошумовая, мина, турель)
  - общее для огнестрела — щелчок пустого, «мало патронов», достать/убрать, затвор, гильзы (латунь/дробь). **Ближнее — по весу взмаха** (лёгкий / средний / тяжёлый) **и типу удара** (клинок / тупой / тяжёлый), не по каждому оружию; **взрывы общие** (гранаты, РПГ, миномёт, бочки).
  - Калибры — 5,45 / 7,62 / 9 мм (не 5,56)
- *Почему / когда:* Решение пользователя 2026-10-16; раскладка — [SoundShortlist/README.md](SoundShortlist/README.md)

### Прицел на ПК (4а)

- Огонь — в точку под мышью (без автонаведения); геймпад — правый стик; телефон — направление движения с автонаведением. Касания не целятся (`Look` = только мышь)
- *Почему / когда:* Этап 4а, 2026-10-17

### Поворот при стрельбе (4а)

- Боевая стойка: корпус держит прицел 1 с после выстрела (без разворота туда-обратно между выстрелами при отступлении), поворот в прицеле плавнее; **ПК — корпус всегда к курсору** (twin-stick), ноги — по движению; телефон — автонаведение со стика движения: конус по ходу, затем ближайшая цель вокруг.
  - Бег спиной/боком без скольжения — анимации стрейфа UAC (шаг 4а)
- *Почему / когда:* Решение пользователя 2026-10-17 (отзыв: «на каждый выстрел перс разворачивается»)

### Два стика на телефоне (Т)

- Телефон по умолчанию — **схема «Два стика»**: левый стик — только движение (ноги), правый — направление огня. Заменяет для телефона «автонаведение со стика движения» (разделы «Прицел на ПК (4а)», «Поворот при стрельбе (4а)»).
- **Огонь, пока правый стик отклонён** за мёртвую зону (как Soul Knight, не «прицел + выстрел при отпускании»): автомат — непрерывно, полуавтомат и ближнее — в своём темпе. Отпустил — огонь стоп, корпус держит направление по боевой стойке (1 с).
- Автонаведение с правого стика — только лёгкий доворот в узком конусе вокруг направления стика; без переключения на ближайшую цель вокруг.
- Правый стик — на месте кнопки Attack; секторы слот 1 / слот 2 / метательное — вокруг него. Бросок целится правым стиком (дальность — по отклонению), без стика — как сейчас.
- **Схема «Авто» остаётся опцией** в настройках управления (текущее поведение: Attack + автонаведение от движения).
- **Реальный геймпад не меняется**: огонь по кнопке, правый стик только целится. Огонь от отклонения — только у экранных стиков.
- *Почему / когда:* Решение пользователя 2026-10-19 (отзыв с телефона: неудобно, что перс сам разворачивается и стреляет по ближайшей цели)

### Восприятие (5б)

  - шумит всё (выстрел, ближний, взрыв, бросок, шаги, двери, подбор), кроме попаданий пуль в стену. Услышал — идёт к источнику, дошёл и никого — снова бродит. Заметил — рык 0,5 с и погоня **без потери игрока** (до смерти). **Зов** умеет только зовущий (всех в радиусе крика, без цепочки).

  - Песочница: спавн группы бродяг/зовущего вдали, переключатель «все охотники / по данным», стена с дверью

### Эффекты монстров и замер (Э3)

- **Смерть** — в конце `CorpseTime` труп за ~0,4 с уходит под землю, в этот момент пых пыли/дыма пака (излучатель). **Оглушение** — звёздочки над головой (частицы пака через излучатель, как горение: `StatusDefinition.Particles`).
  - **Ярость** — красное свечение модели до смерти (`_Glow`, как у чемпионов) + разовая вспышка пака на рыке. **Удар по площади Шамана** — в конце предупреждения сверху падает вид (Замок — огненный шар, Лес — клякса яда, Снег — ледяной ком), затем эффект в центре; механизм общий.
  - **Взрывы при увеличении** — под радиус растут форма, скорость и число частиц, размер частиц — слабо (≈√). **Хвосты Э2** — струя обрезается стеной, остальное поправить без скриншотов (пользователь проверяет в игре). **Выбор эффектов Э3** — агент выбирает сам, пользователь проверяет в игре.
  - **Бенч песочницы** — ёмкость 300 + 64 места под вызванных и поднятых; игрок стреляет из автомата с автонаведением (патроны бесконечны), убийств самим бенчем нет. WebGL-сборка для замера — спросить перед сборкой
- *Почему / когда:* Решения пользователя 2026-10-18

### Способности и офицеры (5в)

- Офицеры живут в тех же массивах `HordeSystem` (поле пути, восприятие, попадания, дроп), отличается только вид — пул GameObject с Animator. Модули 5в: удар, снаряд (прямой / дугой / веером), крик; **рывок и отталкивание — в 5г** с Громилой.
  - **Крикун** — зовущий: заметив игрока, кричит один раз (зов) и сам бежит на игрока, дерётся обычным ударом вблизи; других эффектов у крика нет. **Дальний**: подходит на дистанцию стрельбы (~6–8) при прямой видимости, стреляет, при игроке ближе 3 отступает, у стены — бьёт вблизи
  - лучник — прямой снаряд (линия-предупреждение), плевун — дугой в клетку (круг, лужа кислоты), сосульки — веер из 3 (замедление). Снаряды монстров летят над монстрами (их гасят только стены/препятствия), сбить нельзя — только увернуться; кислотная лужа вредит и монстрам (смерть засчитывается игроку).
  - На игроке — кислота, замедление, оглушение, горение; иммунитет к контролю 2,5 с с видимым признаком. Клипы: крик — `scream` Mixamo, лучник — UAC Bow & Arrow, плевок/сосульки — броски UAC. Дроп офицеров — своя черновая таблица. Черновые статы: Крикун HP 120, 2,0 кл/с
  - Дальний HP 70, 2,2 кл/с, выстрел раз в 2,5 с
- *Почему / когда:* Решение пользователя 2026-10-18

### Громила и двери (5г)

- **Рывок** — с предупреждением (линия), прицел фиксируется; попал в игрока — урон и отбрасывание **без оглушения**; рядовых на пути расталкивает в стороны **без урона** — общий модуль «импульс сквозь орду» (на него ляжет машина-таран).
  - **Отталкивание** — отдельная способность (переиспользуемая), не часть рывка. **Двери**: рядовые не открывают, офицер открывает **сразу**, дверь **остаётся открытой**; Громила выбивает — у двери прочность (черновое значение, баланс — этап 10).
  - Анимации Громилы — черновые: Mixamo Creature Pack и UAC Creature (удар в дверь — обычный удар). Попадание будит бродягу — подтверждено
- *Почему / когда:* Решение пользователя 2026-10-18

### Масса тела (5г)

- У монстра **масса** (по рангу: рядовые 0,15, офицеры 0,5, элита 4, боссы неподвижны; можно задать явно, флаг «неподвижен»), у игрока — 1.
  - Столкновение игрока с монстром делится по массам: рядовых игрок расталкивает почти как раньше, офицеров — с небольшим торможением, Громилу (6) почти не сдвинуть, босса — никак (обходится).
  - Сразу заложено под будущее: расталкивание в толпе по массам, отбрасывание оружием и взрывами и `CrowdImpulse` (рывок, машина) × min(1, 1/масса). Давление толпы на игрока — не делалось (отдельное решение). **God** песочницы гасит урон и состояния, но не отбрасывание

### Чемпионы (5д2)

- **Один аффикс** на чемпиона; общее — **HP ×2, вид ×1,15** (тело в геймплее как у вида), свечение цветом аффикса, дроп на ранг выше. **Быстрый** — скорость ×1,5, атаки ×1,3. **Огненный** — удар поджигает игрока, за ним горящий след (зона монстров, свой огонь его не трогает), иммунитет к горению.
  - **Бронированный** — броня со всех сторон: урон оружия и взрывов ×0,5, зоны и состояния — полностью. **Взрывной** — при смерти через 0,6 с взрыв r 2 (ранит игрока и монстров), перед ним круг-предупреждение. **Вампир** — лечится на 100 % урона, нанесённого игроку (не от убийств).

### Забег (6)

- **Пять подэтапов**: 6а волны и генератор → 6б пауза между волнами → 6в опыт и карточки → 6г смерть и итог → 6д сейв забега и замер A16 (строки плана, раздел 2).
- **Волны — генератор на бюджете с этапа 6** (полностью ручной сценарий не нужен): `WaveScenario` на уровень — список волн; у волны бюджет, разрешённые монстры с весами (стоимость — в `MonsterDefinition` по рангу), обязательные группы (монстр, количество, время, точка), длительность появления, потолок живых. Тот же генератор — основа выживания (этап 16).
  - Волна кончается, когда всё появилось и все убиты (таймера волны нет). Конец уровня — после последней волны (босс — этап 8).
- **Точки появления** — маркер в `LevelData` (с этажом); монстр вылезает (`Emerge`) в радиусе ~2 клеток от точки; точки ближе ~8 клеток к игроку временно не используются. Восприятие появившегося — по данным вида.
- **Пауза между волнами** — черновые 20 с; «Пропустить» = оставшиеся секунды × ставка волны; после паузы дроп волны исчезает (с коротким эффектом).
- **Сложность** — множители в `DifficultyDefinition`: HP, количество, доля старших рангов, редкость дропа, деньги; числа черновые, точные — этап 10.
- **Проверка** — отдельный dev-уровень `Level_Run`: площадка ~60×60 с препятствиями, 4–6 точек появления, сценарий ~5 волн / ~5 мин, запуск из главного меню Maze («Играть»). Песочница остаётся для бенча.
- **Карточки** — первый набор ~12 модулей-статов (урон, скорострельность, перезарядка, магазин, бег, макс. HP, лечение за убийство, радиус подбора, +метательное, сила взрывов, урон по горящим, крит); у карточки редкость и стопка уровней. Карточки банка идей и эволюции — этап 15. Переброс — заглушка rewarded (`IAdsService`), раз на каждое появление карточек.
- **Воскрешение** — полное HP, 2 с неуязвимости, волна отталкивания с оглушением вокруг игрока; rewarded — заглушка рекламы, навык персонажа — флаг в данных (сам навык — этап 11); до двух раз за забег.
- **Итог** вместо звёзд Maze: победа/смерть, волны, убийства, время, деньги забега, ×2 за rewarded, очки; деньги в сейв сразу; `Stars`/`BestTime` из `LevelRecord` убрать.
- **Очки** — сумма очков убитых (по рангу) × множитель сложности + бонус за волну; нужны только для лидерборда выживания, на уровнях — только в итоге.
- **Старт забега до меню этапа 11** — базовый пистолет + одно оружие из dev-настройки уровня, без бустеров; «Продолжить» — кнопка в текущем главном меню при наличии `RunSave`.
- **Деньги и опыт за убийство** — черновые числа в `MonsterDefinition` по рангу; «монетка к HUD» — в 6д.
- **Орда уровня — `HordeDefinition`** (`LevelData.Horde`): виды и их вид, чемпионы, ёмкость, сложность, дроп — для любого уровня; `StressTestDefinition` остаётся только dev (стресс-оружие, автопилот, бенч, оверлеи, песочница); dev-уровень ссылается на оба ассета. Выделено в 6а.
- **6б**: на уровне с волнами дроп **без таймера** — лежит до старта следующей волны, потом исчезает весь (лимит `MaxLying` остаётся; в песочнице — по-старому).
