## Договорённости с пользователем
Цикл (решение пользователя 2026-10-16), повторяется, пока во всех пунктах не станет ровно `нужно_N`:
1. **Пользователь слушает всё разом:** нужное и варианты на выбор оставляет, неподходящее **удаляет**; если считает, что вариантов нужно другое число, — переименовывает `нужно_N.txt`. Свои найденные звуки кидает в **корень** шортлиста.
2. Пишет агенту. Агент: раскладывает звуки из корня по пунктам (нет пункта — заводит; источник в `index.csv` — «пользователь»), запускает `python -I check.py` и выводит: где звуков **меньше** нужного (решаем, искать ли ещё и где), где **больше** (пользователю выбрать), сколько удалено.
3. После добавок — новый снимок `python -I check.py --snapshot`.

Правила:
- Что пользователь удалил — **отклонено, больше не предлагать** (сверять с `snapshot.csv` и `index.csv`/`index_original.csv`).

- Пункт без единого звука помечается `ПУСТО — <причина>.txt` (видно, чего не хватает); заполнился — пометку снять. `нужно_0` — пункт намеренно без своего звука.
